### S4：操作原语序列生成

本步骤基于S3输出的结构化语义特征，利用任务条件化Transformer序列生成模型，在生成过程中引入任务条件约束，以自回归方式生成满足任务语义一致性及操作结构约束的多个候选L3操作原语序列。

#### S41：模型整体架构

所述任务条件化Transformer序列生成模型（TaskConditionedL3TransformerModelV4）包含文本编码模块、条件融合模块、条件化解码模块及输出投影模块四个核心组件，其整体架构如图3所示。模型接收三路输入：S34输出的结构化模板文本（经BERT分词后的token序列）、S33输出的任务类型标识符（task_type_id）、以及当前已生成的L3操作原语序列（自回归过程中逐步扩展）。模型的输出为词表上的概率分布，用于在每个时间步选取下一个操作原语。

#### S42：文本编码模块

文本编码模块采用预训练语言模型BERT对结构化模板文本进行编码，提取任务描述的语义表示。为使预训练语言模型适应GIS领域的专业术语和表达模式，本发明采用部分解冻策略：冻结BERT底层的大部分参数以保留通用的语言理解能力，仅解冻顶部若干层（本实施例中解冻最后2层）进行GIS领域的适应性微调。解冻层采用远小于主模型的学习率（本实施例中BERT部分学习率为1×10⁻⁵，主模型学习率为1×10⁻⁴），以避免破坏预训练权重。

BERT编码器输出的隐藏状态序列长度与输入文本长度相关，为使后续解码器的交叉注意力计算复杂度可控，本发明设计了自适应采样机制（Adaptive Sampling），从BERT变长输出中等间距采样固定数量M个记忆向量（本实施例中M=16）。具体而言，当有效token数不超过M时，直接保留全部有效token的隐藏状态；当有效token数超过M时，在有效范围内等间距选取M个位置（确保首尾位置被保留），取对应位置的隐藏状态作为记忆向量。采样后的记忆向量经线性投影至模型维度d_model后，附加位置编码，作为解码器交叉注意力的键值序列。

文本编码模块同时输出BERT的池化表示向量v_text（即[CLS]标记经池化层后的输出），用于后续条件融合。

#### S43：条件融合模块

条件融合模块将文本语义信息与任务类型信息融合为统一的条件向量，用于在解码过程中注入任务特定的生成偏好。

首先，将任务类型标识符通过可学习的嵌入层映射为任务类型嵌入向量e_task∈R^{d_model}：

$$e_{\text{task}} = \text{Embedding}(\text{task\_type\_id})$$

然后，将文本池化表示v_text经线性投影至d_model维后，与任务类型嵌入向量进行拼接，通过多层感知机映射为条件向量c∈R^{d_model}：

$$c = f_{\text{MLP}}\left([v_{\text{text}}; e_{\text{task}}]\right)$$

其中，[·;·]表示向量拼接操作，f_MLP由线性层→层归一化（LayerNorm）→GELU激活→Dropout依次组成。该融合方式使条件向量同时编码了"用户想做什么"（来自文本语义）和"这属于哪类任务"（来自任务类型嵌入）两方面信息，为后续解码器的逐层调制提供统一的条件信号。

#### S44：条件化解码模块

条件化解码模块是本发明的核心创新组件。传统的条件化Transformer仅在解码器输入层（即token嵌入阶段）注入条件信息，条件信号随着网络层数加深而逐渐衰减。本发明在每个解码器层均采用特征级线性调制（Feature-wise Linear Modulation, FiLM）机制，将条件向量注入解码过程，实现逐层的条件化控制。

解码模块包含N个堆叠的条件化解码器层（本实施例中N=6）。在每个条件化解码器层中，输入首先经过标准的Transformer解码器层处理（包含掩码自注意力、基于记忆向量的交叉注意力和前馈网络），随后经过FiLM调制。FiLM调制的计算方式如下：

$$h_l' = \gamma_l(c) \odot h_l + \beta_l(c)$$

其中，$h_l$表示第$l$层Transformer解码器的输出隐藏状态，$\gamma_l(c)$和$\beta_l(c)$分别为基于条件向量$c$通过第$l$层独立的可学习线性变换生成的缩放参数和偏移参数：

$$\gamma_l(c) = W_{\gamma,l} \cdot c + b_{\gamma,l}$$
$$\beta_l(c) = W_{\beta,l} \cdot c + b_{\beta,l}$$

$\odot$表示逐元素乘法（Hadamard积），$h_l'$为调制后的隐藏状态，传递至下一层解码器或输出层。

为保证训练初期模型行为的稳定性，所述缩放参数$\gamma_l$初始化为单位值（即$W_{\gamma,l}$初始化为单位矩阵，$b_{\gamma,l}$初始化为零向量），所述偏移参数$\beta_l$初始化为零值（即$W_{\beta,l}$和$b_{\beta,l}$均初始化为零）。这种初始化策略使得FiLM模块在训练初期等价于恒等变换（$h_l' \approx h_l$），不会干扰解码器的标准行为，随着训练进行逐渐学习到有意义的条件调制模式。

此外，在token嵌入阶段同样施加一次FiLM调制：将输入的L3操作原语token经嵌入层映射后，使用条件向量通过独立的FiLM参数进行调制，再添加正弦位置编码，作为第一层解码器的输入。因此，条件向量共在N+1个位置（1次输入层 + N次解码器层）对序列表示进行调制，确保任务条件信息在模型的各个抽象层次上均能发挥作用。

解码器层内部采用Pre-Norm架构（层归一化置于注意力/前馈网络之前），注意力机制包含d_model/d_head个注意力头（本实施例中d_model=256，注意力头数为8），前馈网络维度为4倍d_model（本实施例中为1024）。解码器自注意力使用上三角因果掩码，确保自回归生成时每个位置仅能关注当前及之前的token。

#### S45：输出投影模块与权重共享

输出投影模块将解码器最终层输出的隐藏状态映射至操作原语词表空间，计算各操作原语的生成概率。本发明采用权重共享策略（Weight Tying），即输出投影矩阵与token嵌入矩阵共享同一组权重参数：

$$P(y_t \mid y_{<t}, c) = \text{softmax}(E^\top \cdot h_t')$$

其中，$y_t$表示第$t$步生成的操作原语，$y_{<t}$表示已生成的操作原语序列，$E$为共享的词嵌入矩阵，$h_t'$为经条件调制后的第$t$步隐藏状态。权重共享减少了模型参数量，同时在嵌入空间中建立了输入表示与输出预测之间的一致性约束。

此外，操作原语的词嵌入矩阵可选择使用在知识图谱上通过图神经网络预训练获得的L3嵌入向量进行初始化，从而将操作原语之间的结构化语义先验（如分类层次关系、常见共现模式等）引入模型的表示空间。

#### S46：辅助任务设计

为增强模型的任务感知能力和序列长度控制能力，本发明在主序列生成任务之外引入了三个辅助任务：

（1）序列长度预测任务：利用解码器在起始标记位置的隐藏状态表示，通过两层前馈网络回归预测目标序列的长度。该辅助任务促使模型在生成初期即形成对目标序列长度的合理预期，减少过长或过短序列的生成概率。长度预测采用对数尺度的均方误差损失（MSE on log-length），以避免长序列在原始尺度上主导损失值：

$$\mathcal{L}_{\text{len}} = \text{MSE}(\hat{l}, \log(l^*))$$

其中$\hat{l}$为模型预测的对数长度，$l^*$为目标序列的真实长度。

（2）任务分类任务：将序列的全局表示（通过掩码平均池化获得）经投影后进行任务类型分类，采用交叉熵损失。该任务增强了模型对不同任务类型之间差异的感知能力，使得条件融合模块学到的条件向量能够更好地区分不同类型的生成模式。

（3）转移合法性正则化：基于训练数据中统计得到的操作原语转移矩阵，对模型在每个时间步分配给非法转移的概率质量进行惩罚，鼓励模型生成的转移模式符合训练数据中观察到的操作原语先后顺序规律。

最终的训练损失为各项损失的加权和：

$$\mathcal{L} = \mathcal{L}_{\text{CE}} + \lambda_1 \mathcal{L}_{\text{len}} + \lambda_2 \mathcal{L}_{\text{cls}} + \lambda_3 \mathcal{L}_{\text{trans}}$$

其中$\mathcal{L}_{\text{CE}}$为带标签平滑的频率加权交叉熵主损失（对低频操作原语适当提升权重，缓解类别不均衡问题），$\lambda_1$、$\lambda_2$、$\lambda_3$为各辅助损失的权重系数。

#### S47：训练策略

模型训练采用渐进式训练策略，分阶段逐步提升训练难度：

（1）教师强制阶段（Teacher Forcing）：在训练初期，解码器在每个时间步均以真实目标序列作为输入，模型仅需学习在给定正确历史的条件下预测下一个token。该阶段使模型快速收敛并建立基本的序列生成能力。

（2）计划采样阶段（Scheduled Sampling）：在教师强制阶段结束后，逐步引入自回归采样。具体而言，在每个训练batch中，以概率ar_ratio选择使用自回归方式生成输入（模型使用自身上一步的预测作为当前步输入），以概率1-ar_ratio继续使用教师强制。ar_ratio从较小的初始值线性增长至较大的终止值，同时教师强制概率tf_ratio从较大值线性衰减至接近零。自回归采样时使用核采样策略（Nucleus Sampling），以温度参数调节分布平滑度并截断低概率尾部，增加生成多样性同时避免退化。

（3）课程学习：在训练前期仅使用较短的序列样本进行训练（序列长度不超过预设阈值），随着训练进行逐步引入更长的样本，使模型先掌握短序列的生成规律后再学习长序列的复杂模式。

BERT编码器部分与模型主体部分采用差异化学习率，BERT解冻层的学习率设为主体部分的1/10，以避免微调过程中破坏预训练语言模型的通用语义表示。训练过程使用混合精度（AMP）加速，梯度裁剪阈值设为1.0，并采用基于验证集损失的早停策略。

#### S48：推理策略

在推理阶段，本发明采用分组多样性Beam Search结合多因子候选评分的策略，从模型中生成多条差异化的L3操作原语候选序列。

**分组多样性Beam Search**：将总beam宽度划分为G个组（本实施例中G=5），每组包含K个beam（本实施例中K=4）。各组独立进行beam搜索，组间施加基于Hamming距离的多样性惩罚：

$$\text{score}_{\text{group}}(y_t) = \log P(y_t \mid y_{<t}, c) - \lambda \sum_{g' < g} \mathbb{1}[y_t \in \text{selected}_{g'}]$$

其中$\lambda$为多样性惩罚系数（本实施例中$\lambda$=0.5），$\text{selected}_{g'}$为编号小于当前组的各组在当前步已选择的token集合。这种组间惩罚机制强制不同组探索不同的生成路径，避免所有beam收敛至相同或高度相似的序列。

**非对称长度惩罚**：在候选评分中引入非对称长度惩罚机制，反映GIS实践中"宁短勿长"的偏好——较短的序列可能遗漏处理步骤但不会引入错误操作，而过长的序列往往包含冗余或循环操作：

$$s_{\text{len}} = \begin{cases} \exp(-\alpha_1 |d|) & \text{if } d \leq 0 \text{（偏短，轻惩罚）} \\ \exp(-\alpha_2 d) & \text{if } d > 0 \text{（偏长，重惩罚）} \end{cases}$$

其中$d = l - l_{\text{exp}}$为实际长度与期望长度之差，$\alpha_2 > \alpha_1$（本实施例中$\alpha_1$=0.05，$\alpha_2$=0.2）。期望长度$l_{\text{exp}}$根据任务类型从离线预计算的长度统计中动态获取（取该任务类型训练样本的中位数长度，上限为15），若无对应统计则使用默认值。

**逐任务类型动态长度适应**：系统在离线阶段统计训练数据中各任务类型对应的L3序列长度分布（中位数、均值、P90等），在推理时根据S33识别的任务类型动态设置期望长度，使模型针对不同复杂度的任务生成适当长度的序列。

**多因子候选评分**：所有完成的候选序列按以下多因子加权公式计算最终得分：

$$\text{score} = w_p \cdot s_{\text{logprob}} + w_t \cdot s_{\text{trans}} + w_l \cdot s_{\text{len}} + w_d \cdot s_{\text{div}}$$

其中$s_{\text{logprob}}$为归一化对数概率（衡量模型自身对该序列的置信度），$s_{\text{trans}}$为转移合法性评分（已生成序列中合法转移占比），$s_{\text{len}}$为上述非对称长度评分，$s_{\text{div}}$为多样性评分（与其他候选的平均Jaccard距离）。各因子权重通过实验确定。

**后处理**：对生成的候选序列进行后处理，包括连续重复token去除、ABAB振荡模式检测（出现三次及以上的token仅保留首次出现）、以及尾部循环截断，消除自回归生成中常见的退化模式。

最终输出经评分排序和后处理的Top-N条候选L3操作原语序列（本实施例中N=3），供后续步骤S5进行具体算子映射。
