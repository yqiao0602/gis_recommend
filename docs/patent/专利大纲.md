# 专利大纲

## 专利名称

**一种基于Transformer序列生成与知识图谱融合推理的地理处理模型自动构建方法**

---

## 一、说明书摘要

> 约 300 字，概括整体方法流程和有益效果

要点：
- 属于计算机和 GIS 领域
- 核心流程：知识图谱构建 → 层次化操作原语分类体系 → LLM 任务理解 → Transformer 序列生成 → Beam Search 算子映射 → GraphRAG+LLM 融合推理 → 迭代链修复
- 关键创新：任务条件化 Transformer 自回归生成、三级层次化操作原语体系、知识图谱增强的多阶段融合推理
- 有益效果：全自动构建、结构合理性保证、可执行性验证

## 三、权利要求书

### 权利要求 1（独立权利要求）——整体方法

一种基于 Transformer 序列生成与知识图谱融合推理的地理处理模型自动构建方法，其特征在于，所述方法包括：

- **S1**：构建知识图谱——抽取多源 GIS 软件中的算子及其输入输出参数，形成算子、数据类型、算法等实体节点及其语义关联关系，以图数据库进行管理
- **S2**：构建层次化操作原语分类体系——建立三级抽象分类（L1 大类 → L2 子类 → L3 操作原语），并将知识图谱中的具体算子映射至 L3 操作原语
- **S3**：任务语义理解——接收自然语言查询，通过大语言模型提取任务名称、类型、约束条件等结构化语义特征
- **S4**：操作原语序列生成——利用任务条件化 Transformer 解码器模型，以自回归方式生成 L3 操作原语序列，并通过多样性约束的分组 Beam Search 生成多条候选序列
- **S5**：算子映射与候选链生成——基于知识图谱中 L3 操作原语与具体算子的映射关系，结合语义相似度和输入输出兼容性评分，通过 Beam Search 将 L3 序列映射为具体的算子链
- **S6**：多阶段融合推理与链修复——采用 GraphRAG 结构化评分、大语言模型语义评分和迭代链修复机制，对候选算子链进行综合评估与优化，输出最优的地理处理模型

### 权利要求 2（从属）——知识图谱构建细节

从属于权利要求 1，进一步限定 S1 中知识图谱的构建方式：
- 节点类型：算子（QGIS_Operator、GEE_Operator）、操作原语（L3_Primitive）、类别（L2_Category、L1_Category）、输入（Input）、输出（Output）、数据类型（DataType）
- 关系类型：maps_to_l3（含置信度）、belongs_to_l2、belongs_to_l1、hasInput、hasOutput、links_to、compatible_with
- 图数据库管理（Neo4j）与 Cypher 查询

### 权利要求 3（从属）——层次化操作原语分类体系

从属于权利要求 1，进一步限定 S2 中的分类体系：
- L1 大类（10 类）：数据管理、空间分析、地形分析等
- L2 子类（78 类）：缓冲区分析、叠置分析、坡度计算等
- L3 操作原语（350 类）：具体原子操作
- 基于 GEE 脚本的监督样本构建：解析脚本提取操作序列，映射为 L3 标注序列
- 多源算子到 L3 的语义映射方法（含置信度评分）

### 权利要求 4（从属）——任务条件化 Transformer 模型

从属于权利要求 1，进一步限定 S4 中的模型架构：
- BERT 文本编码器：对任务描述进行语义编码，提取固定数量的记忆向量
- FiLM（Feature-wise Linear Modulation）条件注入：在 Transformer 解码器的每一层通过可学习的缩放和偏移参数注入任务条件信息
- 图嵌入初始化：利用知识图谱上训练的图神经网络嵌入向量初始化 L3 词表的 token embedding
- 输出层权重共享：解码器输出投影层与输入 embedding 层共享权重

### 权利要求 5（从属）——多样性约束的序列生成

从属于权利要求 1，进一步限定 S4 中的序列生成策略：
- 分组多样性 Beam Search：将 beam 分为多组，组间施加 Hamming 多样性惩罚
- 非对称长度惩罚：对短于期望长度的序列施加温和惩罚，对长于期望长度的序列施加强惩罚
- 动态期望长度：根据任务类型的统计分布动态设定每种任务类型的期望序列长度
- 多因子候选评分：综合序列概率、状态转移合法性、长度适配度和多样性的加权评分

### 权利要求 6（从属）——算子映射与 I/O 兼容性

从属于权利要求 1，进一步限定 S5 中的算子映射：
- 语义相似度融合评分：结合预计算的语义余弦相似度和知识图谱置信度的加权评分
- I/O 类型归一化：将多种几何类型归一化为粗粒度类型（矢量/栅格），进行相邻算子间的输入输出兼容性评估
- 带约束的 Beam Search：限制未知算子比例、关键位置约束（首尾位置不允许未知算子）
- 类型化未知占位符：对无法映射的操作原语生成带功能分类标签的占位符

### 权利要求 7（从属）——多阶段融合推理

从属于权利要求 1，进一步限定 S6 中的融合推理：
- 第一阶段（GraphRAG 结构化评分）：基于知识图谱查询，综合算子置信度、已知算子比例、I/O 兼容性和链验证结果的加权评分
- 第二阶段（LLM 语义评分）：将候选算子链的结构化描述输入大语言模型，获取语义合理性评分，与结构化评分融合
- 第三阶段（迭代链修复）：按严重度排序定位最差 I/O 不兼容问题，从知识图谱检索同类替代算子并经 I/O 预过滤，由 LLM 选择最佳替代，采用深拷贝回滚机制确保修复不劣化
- 交互式追问：输出最优算子链后，接收用户问询，基于知识图谱检索相关上下文信息，输入大语言模型生成解释性应答

### 权利要求 8（从属）——训练策略

从属于权利要求 4，进一步限定 Transformer 模型的训练方法：
- 渐进式自回归训练（Scheduled Sampling）：从纯教师强制逐步过渡到自回归训练，TF 比率和 AR 批次比率双重渐进衰减
- 课程学习：按序列长度分阶段引入训练样本（短序列 → 中等序列 → 全长度序列）
- 多任务辅助损失：主损失（交叉熵）+ 序列长度预测损失 + 任务分类损失
- REINFORCE 序列级微调（可选）：采用自我批判序列训练（SCST），以集合 F1、最长公共子序列比率和位置准确率的加权组合作为奖励函数

## 四、说明书

### 1. 技术领域

- 计算机科学与地理信息系统（GIS）交叉领域
- 涉及深度学习序列生成、知识图谱、自然语言处理

### 2. 背景技术

> 可基本沿用原专利，增加以下内容

- 现有 GIS 建模工具的不足（手动拖拽、依赖专业知识）
- 已有方法的局限：
  - 纯语义检索方法：只能检索单个算子，无法生成有序操作序列
  - 图神经网络方法：依赖候选子图构建，难以端到端生成完整操作流程
  - 大语言模型直接生成：缺乏领域结构约束，生成结果的可执行性无法保证
- **新增**：序列生成中的 exposure bias 问题（教师强制训练与自回归推理的分布不匹配）
- **新增**：缺乏统一的操作抽象层，导致跨平台算子推荐困难

### 3. 发明内容

#### 3.1 技术问题

1. 如何从自然语言任务描述自动生成有序的地理处理操作序列
2. 如何保证生成的操作序列在映射为具体算子后的结构合理性和可执行性
3. 如何建立跨平台的统一操作抽象，支持不同 GIS 软件之间的算子映射

#### 3.2 技术方案（概述 S1-S6）

#### 3.3 有益效果

1. 实现了从自然语言到可执行地理处理模型的全自动构建
2. 通过层次化操作原语体系，实现了跨平台的统一操作抽象
3. 通过任务条件化 Transformer 序列生成，实现了有序操作流程的端到端生成
4. 通过多阶段融合推理与迭代链修复，保证了算子链的结构合理性和可执行性
5. 通过渐进式自回归训练策略，缓解了序列生成中的 exposure bias 问题

### 5. 具体实施方式

#### S1：知识图谱构建（~2 页）

> 可大量复用原专利 S1（S11、S12），调整节点/关系类型

- S11：多源算子元数据获取（QGIS、GEE、GRASS、GDAL、SAGA 等）
- S12：图 Schema 定义（节点类型、关系类型、属性字段）
- S13：Neo4j 图数据库存储与 Cypher 查询接口

#### S2：层次化操作原语分类体系构建（~2 页，全新）

- S21：三级分类体系设计（L1 大类 10 → L2 子类 78 → L3 操作原语 350）
- S22：分类标准与命名规范
- S23：多源算子到 L3 的语义映射（GEE 方法 → L3 映射，QGIS 算子 → L3 映射，含置信度）
- S24：基于 GEE 脚本的监督样本构建（解析脚本 → L3 操作序列标注）

#### S3：任务语义理解（~1.5 页）

> 可部分复用原专利 S3（S31、S32、S33），扩展 LLM 多阶段提取

- S31：自然语言查询预处理
- S32：LLM 结构化信息提取（任务名称、描述、类型、约束条件、预估步数）
- S33：任务类型识别（混合检索：嵌入相似度 + LLM 选择 → task_type_id）

#### S4：操作原语序列生成（~4 页，核心创新）

- S41：任务条件化 Transformer 解码器架构
  - BERT 文本编码器与记忆向量提取
  - 任务类型嵌入与条件向量融合（MLP 融合）
  - FiLM 逐层条件注入机制（可学习的 γ/β 参数，恒等初始化）
  - 图嵌入初始化（知识图谱上训练的 GNN 嵌入 → token embedding 初始化）
  - 输出层权重共享
- S42：训练策略
  - 渐进式自回归训练（Scheduled Sampling）：TF 比率衰减 + AR 批次比率渐进
  - 课程学习（短→中→全长度序列）
  - 多任务辅助损失（长度预测 + 任务分类）
  - Token 频率加权（逆频率平滑）
  - REINFORCE 序列级微调（SCST，可选阶段）
- S43：多样性约束的候选序列生成
  - 分组多样性 Beam Search（组间 Hamming 惩罚）
  - 温度采样与核采样（Nucleus Sampling）
  - 非对称长度惩罚与动态期望长度
  - 多因子评分（概率/转移/长度/多样性）
  - 序列后处理（去重复、ABAB 模式折叠）

#### S5：算子映射与候选链生成（~2 页）

- S51：L3 操作原语到具体算子的映射检索（知识图谱 Cypher 查询）
- S52：语义相似度融合评分（预计算余弦相似度 + 置信度加权）
- S53：I/O 类型归一化与兼容性因子计算
- S54：带约束的 Beam Search 算子链生成
- S55：类型化未知占位符处理

#### S6：多阶段融合推理与链修复（~3 页，核心创新）

- S61：GraphRAG 结构化评分
  - 知识图谱多跳查询获取算子详细信息
  - 综合评分公式（置信度 × 0.4 + 已知比例 × 0.2 + I/O 兼容 × 0.2 + 验证 × 0.2）
- S62：LLM 语义评分与融合
  - RAG 上下文构建（算子信息、I/O 类型、链结构）
  - LLM 对候选链评分（0-10 分制）
  - 融合公式（结构化 × 0.5 + LLM × 0.5）
- S63：迭代链修复
  - 严重度排序（双端不兼容 > 单端不兼容 > 兼容）
  - I/O 预过滤替代算子（双端兼容 > 部分兼容 > 丢弃）
  - LLM 辅助最优替代选择
  - 深拷贝回滚机制（修复后重新验证，不改善则回滚）
- S64：最终结果输出（最优算子链 + 结构化描述 + 自动化模型）

#### 实验验证（~1.5 页）

- 数据集：54,835 个 GEE 工作流标注数据
- 评估指标：Set F1、Token Accuracy、LCS Ratio、L2 Accuracy
- 实验结果对比（V4.2 → V4.3 的改进数据）
- 消融实验思路
