### 3-2、实验数据处理

本专利研发过程中，围绕“自然语言地理信息任务 -> 平台无关操作原语序列 -> 目标平台 QGIS 算子链”的技术路线，对多源地理处理语料、QGIS 算子目录、GEE/QGIS 工作流样本和操作原语映射关系进行了清洗、对齐和训练样本构建。

#### 3-2-1、多源地理处理语料与 QGIS 算子目录整理

研发过程中首先对 QGIS 开源工作流语料和 QGIS processing 算子目录进行审计。审计结果显示，QGIS 算子目录包含 1292 个 algorithm id，初始可映射至 L3 操作原语的 algorithm id 为 454 个；其中 `standard` 工作流数据包含 1045 行标准处理流程，识别出 4741 个工具调用，已映射工具调用 2180 个。

【插入截图：`outputs_v2/diagnostics/qgis_corpus_audit/qgis_corpus_audit.md` 或 `qgis_workflow_l3_coverage.json` 中的统计结果】

图3-4 QGIS 开源工作流语料审计与算子映射覆盖统计。

上述审计过程还输出了未映射高频工具列表，例如 `native:reprojectlayer`、`native:fixgeometries`、`native:mergevectorlayers`、`gdal:warpreproject`、`native:extractbyexpression`、`gdal:polygonize`、`gdal:rasterize` 等。这些结果用于指导后续 QGIS 算子到操作原语的映射扩展和清洗。

【插入截图：`qgis_workflow_l3_coverage.json` 中 `top_unmapped_tools` 部分】

#### 3-2-2、QGIS 候选算子链数据集构建

在完成 QGIS 工具审计和映射关系清洗后，系统构建了 QGIS 候选算子链数据集。统计结果显示，数据集中共包含 3053 条记录、972 条唯一算子链，其中 1687 条具有 L3 操作原语映射；按数据类型划分，纯矢量链 1628 条，纯栅格链 418 条，矢量/栅格混合链 931 条。

【插入截图：`outputs_v2/qgis_chain_dataset_summary.json`】

图3-6 QGIS 候选算子链数据集构建结果。

同时，系统进一步构建了面向矢量处理任务的规范化 planning 数据集，共包含 2319 条记录，其中 1046 条具备完整 L3 标注。数据集中包含 1598 条矢量任务、456 条栅格任务和 265 条混合任务。高频规划步骤包括坐标转换、缓冲区分析、属性过滤、字段计算、几何修复、空间裁剪、空间聚合、图层合并和空间叠置等。

### 3-4、实验结果与处理效果

端到端评估结果显示，系统能够将自然语言地理信息任务转换为 L3 操作原语链，并进一步映射为 QGIS 候选算子链。在 50 个展示任务中，L3 rule-usable 为 49/50，QGIS top-1 valid 为 50/50，QGIS combined bridge 为 50/50，平均 QGIS quality 为 1.0000。

【插入截图：`outputs_v2/diagnostics/end_to_end_probe_50/end_to_end_showcase_eval.md` 的 Summary 部分】

图3-13 自然语言任务到 QGIS 算子链的端到端生成评估结果。

评估报告中记录了多类任务样例，包括遥感分类、植被监测、森林扰动分析、水体提取、地表温度统计等。每个样例均记录自然语言任务描述、生成的 L3 操作原语链以及映射得到的 QGIS 算子链。

【插入截图：`end_to_end_showcase_eval.md` 中 Forest disturbance mapping 或 Vegetation condition monitoring 样例】

图3-14 自然语言任务、L3 操作原语链与 QGIS 可执行算子链对应示例。

【插入截图：`selector_report.md` 中 Usable Rate Comparison 和 Final Selected Source Distribution 部分】

## 5、发明人贡献说明

本专利围绕自然语言地理信息任务到可执行地理处理算子链的自动构建开展研发，研发工作包括地理处理知识体系设计、多源算子数据整理、平台无关操作原语体系构建、序列生成模型训练、QGIS/GEE 算子映射、候选算子链评估与修复、实验验证及专利申请文件整理等环节。各发明人结合自身研究方向和研发分工，对本专利技术方案的形成作出了如下贡献。

张明达：作为第一发明人，负责本专利总体技术路线和研究方向把关，提出面向地理信息任务自动处理的整体研发目标，指导将地理信息处理领域知识、跨平台算子互操作和自动化模型构建相结合。其主要贡献包括：确定以地理处理知识图谱、平台无关操作原语体系、任务语义解析、操作序列生成和算子链修复为核心的技术框架；指导地理处理操作大类、操作子类和操作原语的层次化设计思路；对多源 GIS 算子、空间数据类型、地理处理工作流等领域知识的组织方式进行审查；对专利技术方案中的应用场景、技术问题、有益效果和可实施性进行把关；参与专利申请文件和创造性补强材料的审阅，确保方案表述符合地理信息系统领域的技术逻辑。

乔雲：负责本专利核心研发实现和实验验证工作，是系统工程实现、数据处理和模型训练的主要完成人。其主要贡献包括：搭建地理信息任务处理模型自动构建系统的代码工程和实验环境；采集、整理和审计 QGIS/GEE 相关算子数据及开源工作流语料；构建 QGIS 算子链数据集、canonical vector planning 数据集和 Step8 训练包；完成 QGIS/GEE 具体算子与 L3 操作原语之间的映射、清洗、覆盖度统计和样本对齐；实现或组织条件化序列生成模型训练、偏好优化、候选链检索、执行感知选择器和质量评估流程；开展端到端实验，验证自然语言任务到 L3 操作原语链、再到 QGIS 候选算子链的生成效果；整理实验输出、评估报告、研发截图材料和专利技术说明文档，为本专利的技术交底和申请文件撰写提供主要技术支撑。

成晓强：负责地理信息处理业务场景、GIS 工作流合理性和目标平台可执行性方面的技术支持。其主要贡献包括：结合地理信息处理和空间分析应用需求，对系统生成的候选算子链是否符合常见 GIS 处理逻辑进行审查；参与分析缓冲区分析、空间叠置、坐标转换、几何修复、栅格裁剪、分区统计等典型任务中的算子组合关系；对 QGIS 算子链的输入输出衔接、处理顺序、业务可解释性和应用可行性提出修改意见；协助补充实验过程、业务场景和功能展示材料；参与专利申请材料中关于目标平台执行、算子链可用性和地理处理业务适配性的论证。

综上，张明达主要负责总体技术路线、领域知识体系和专利方案把关；乔雲主要负责系统研发实现、数据集构建、模型训练与实验验证；成晓强主要负责 GIS 业务场景、算子链合理性和应用验证支持。三位发明人的分工共同支撑了本专利从技术构思、系统实现、实验验证到申请材料形成的完整研发过程。
