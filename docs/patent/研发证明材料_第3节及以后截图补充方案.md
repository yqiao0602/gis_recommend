## 3-3、模型训练与参数优化过程（两阶段）

本系统采用两阶段训练策略：

- **阶段一**：训练 CSG-Geo 条件化序列生成模型（`TaskConditionedL3TransformerModelV4`），通过 `ScheduledSamplingTrainerV4_6` 实现计划采样+课程式训练
- **阶段二**：训练操作原语集合预测器（`L3SetPredictor`），为推理阶段提供 token 出现概率和计数的软先验
