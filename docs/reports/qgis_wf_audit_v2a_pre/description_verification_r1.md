## 核心结论

1. **不是幻觉问题，是表达性问题**：描述真实（0 矛盾 + 源码对账过）、提取真实；风险在 ~25–30% 的工作流核心逻辑在 Python 层，QGIS 算子链只覆盖外围
2. **对监督质量的影响**："部分一致"行教的是"任务→脚本用过的算子（真子集）"——不是错误监督，是弱信号；有 arguable 价值（模型学从任务中提取 QGIS 相关部分），但不应与强信号等权
3. **对 2,265 的量化含义**（初估，CI 宽）：
   - 严格口径（一致 + 链承载任务主语义）：≈ 1,580 ± 区间
