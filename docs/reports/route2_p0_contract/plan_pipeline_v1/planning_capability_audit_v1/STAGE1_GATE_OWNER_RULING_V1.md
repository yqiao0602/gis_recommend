## 裁定 0：主线排序

- Stage 1 规划能力通过独立验收之前，不进入 QGIS 算子学习（Stage-2 方向）阶段。
- 训练不在桌上：协议冻结前不启动新训练、不调整模型架构、不因单个指标表现临时修改验收标准。
- "通过"= 在预先定义的独立测试上达到进入下一阶段所需的能力标准，不等于完美通用规划。

## 裁定 1：依赖评测 = 方案 (a)，显式依赖 gold 延后

三层口径：

1. **v1 必测**：步骤集合正确性、顺序敏感指标、相邻步骤关系、任务条件变化时的步骤调整；
2. **v1 条件性测量**：仅当现有 gold 可可靠推导结构关系时才测；推导不出标 unknown，
   禁止伪造依赖标签；
3. **v2 补测**：独立依赖标注集（前置条件、输入输出连接、分支汇合、DAG 合法性）。

评价漏洞警示（owner）：LCS 与邻接指标能检验顺序一致性，**不能证明语义依赖正确**——
顺序与金标完全相同仍可能存在不合理数据流。

**PCA v1 落实方式**：金标人工新撰并自带 `dependencies` 字段（PCA §2.6）——属第 2 层
"gold 可靠推导"分支，故依赖准确率可作核心指标（§4.1）；A 组 GEE canonical chain 仅作
参考证据、禁止直译为金标（§2.1），满足"禁伪造"。

**v1 结论措辞上限**："现有证据支持/不支持 Stage 1 的步骤选择与顺序（含金标可靠推导的
依赖）规划能力"；**不得**升级为"完整工作流规划能力已证明"。

## 裁定 2：外部评测集 = 方案 (b)，补充轴

原则：

1. 主验收集由冻结的内部数据和人工裁定样本构成；
2. 外部集（候选：GeoAnalystBench，Apache-2.0）单独报告，不与内部指标混合计算；
3. 转换保留原任务语义要求，不把目标代码中的实现步骤泄漏给规划模型；
4. 若转换丢失重要任务约束 → 仅作参考实验，不纳入 Stage 1 硬性通过条件。

**登记**：PCA v1 未含外部轴（60 任务全部内部构建）。本裁定不阻塞 PCA Phase 1–4；
外部轴作为 PCA 之后的补充泛化证据另行立项（转换可行性验证先行）。
