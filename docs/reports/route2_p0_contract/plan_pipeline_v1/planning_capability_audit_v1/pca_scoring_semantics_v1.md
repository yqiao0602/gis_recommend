# PCA 评分语义规格 v1（round-15 三边界冻结；Stage-4 评分代码的消费逻辑）

> 本文件是 Stage-4 评分代码的**消费逻辑规格**：C-01 三分支判定、C-03 语义有效性、
> F2 三状态评分含义。机械检查负责字段/状态/规则调用一致性；语义评判按本文件由
> judge 依冻结协议执行——三种状态**不能退化为"有文字就通过"，也不允许正则匹配
> 数字/关键词代替语义评判**。

## 1. C-01 建筑人口三分支判定

| 路线 | 判定 |
|------|------|
| **总量分配方法**（面积比例分配等） | 按方法是否满足建筑人口估计目标判断（栅格密度×面积的总量的积分语义正确即合格） |
| **质心代理路线** | 三要件逐查（缺任一 = 该步估计语义不完整，计步骤缺陷）：(a) 声明代理假设；(b) 解释密度→建筑人口的转换（如 密度×footprint 面积或等价机制）；(c) 说明估计的限制 |
| **无效路线** | 仅声明"建筑面积相同"或将密度值**直接当作人口总量**（无转换机制）→ 该步骤不通过 |

## 2. C-03 downstream-order 标识符的语义有效性

满足 = 以下任一：
- 标识符**表达可解释的上下游顺序**（如 order 值单调对应流向）；
- 标识符**关联到明确的河网方向规则**（计划中声明所用规则）。

不满足 = 字段非空但无方向语义（任意递增编号且无流向关联）。算法自由，语义不可取消。

## 3. F2 `parameter_availability` 三状态评分语义（冻结）

| 状态 | 评分要求 |
|------|----------|
| `selectable` | 检查：给出**可用**选择，且该选择与任务目标**相容**（相容性为语义判断，非词面命中） |
| `selectable_with_declaration` | 上述之外，还须**说明必要假设或数据需求**（例：C-05 洲界来源命名或声明为外部输入需求） |
| `selectable_with_suitability_statement` | 上述之外，还须**说明选择与任务目标/数据特征/测量要求的适用性**（例：C-06 CRS 的长度变形适用性） |

**机械/语义分工**：机械检查验证 (a) 字段存在、(b) 状态值合法、(c) 评分代码按状态调用
对应规则；相容性/充分性/适用性为语义评判，judge 按本规格执行。

## 4. 通用评分纪律（重申既有冻结条款）

- 每项扣分 `evidence_source` ∈ {task_text, gold_constraint, model_output}；
- 原链结构观察不单独作为扣分来源；欠定义项不因选择不同合理路线而扣分；
- 展示要求独立计分维度；apply-or-declare 谓词用于全部 selectable 参数。
