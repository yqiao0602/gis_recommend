## 1. 三字段审查口径（owner 批次四提出，自本登记起为 B 轨审查表标准字段）

| 字段 | 可选值 |
| --- | --- |
| 指令变化是否要求结构变化 | 是 / 否 / 不确定 |
| 当前粗标签是否能表达关键差异 | 足够 / 可能不足 / 不足 / 不确定 |
| 当前链条差异是否有证据支持 | 有依据 / 无明显依据 / 暂无法判断 / 不适用（链相同） |

配套纪律（owner 原文）：不能把"链相同"直接判为正确，也不能把"链不同"判为更好；
三个独立概念必须分开——①结构相同是否合理；②粗粒度标签是否掩盖真实差异；③原始
工作流标签本身是否足以表达指令全部步骤。**"粗标签表达不了"不得误判为"应当结构不同"。**

## 3. 机械核验修正：DIFF-20（登记人执行，owner 实质判断保留）

**owner 判读前提**："两条链完全相同，分组与链条不一致，应标记为同结构。"

**登记人机械核验（对 `Q23_MECHANICAL_RESULTS_V1.json` DIFF-20 记录）**：

- Chain A = 39 token，Chain B = 35 token；**二者并非完全相同**——A 比 B 恰好多一个
  重复的季节块 `RASTER_LOAD -> SPATIAL_FILTER -> TEMPORAL_FILTER -> BAND_SELECT`
  （7 次 vs 6 次），其余逐 token 一致。
- **分组机械上无误**：抽样脚本（`scripts/b_track_q23_pool_audit_v1.py`）按
  `tmpl_set(a) != tmpl_set(b)`（两侧指令映射的模板集合是否相等）划分 SAME/DIFF，
  DIFF-20 两侧模板确实不同，入 DIFF 组成立。
- **误判原因 = 审查表渲染**：39-token 高重复链在 MD 中并排展示，肉眼不可辨 1 个重复块
  的差异。**仪器教训**：后续审查表对 RLE 采用游程计数渲染（如 `×7`）并附自动链 diff
  列（本登记配套的核验包已实施）。
- **owner 实质判断保留且加强**：该差异 = 单个重复块的计数增量，与 Q3"差异=局部小变体"
  同型；**不能作为"任务变化驱动结构变化"的强正例**，计为弱变体。
- 处置：DIFF-20 保留在近重复分析中、标记 `weak_variant`；"分组需要质量检查"一项已
  关闭（检查完成，无分组 bug）。

## 4. owner 阶段性结论（两批 SAME + 两批 DIFF 合并）

1. **暂无任何一组可仅凭现有材料判定"必须改变结构却被标为相同"（C 类 = 0）**；也暂无
   一组可判定"数据错误地把无关差异标成了结构差异"。当前 30 类粗标签粒度不足以支撑
   更强的正负判定。
2. **SAME 批核心信息**：任务描述存在差异并不必然要求工作流结构变化；真正需要关注的是
   差异是否改变了分析目标、必要操作、依赖关系或输出要求。
3. **三个层次必须分开**（对后续双层表示设计的直接输入；不能要求单一 30 类序列同时承担
   两类语义）：

| 层次 | 核心问题 | 典型样本 |
| --- | --- | --- |
| 分析结构 | 是否需要增加/删除/调整高层步骤 | SAME-12、SAME-16、DIFF-3 |
| 操作语义 | 同一粗标签是否掩盖了不同操作 | SAME-15、SAME-19、DIFF-14、DIFF-15、DIFF-19 |
| 参数与任务约束 | 结构相同但数据/阈值/时间粒度/输出要求不同 | SAME-11、SAME-14、SAME-20 |

4. **三个假设待原始程序核验**（DIFF 批）：①近重复指令的结构变化不总有清晰语义依据
   （DIFF-4/6/12）；②真正的任务差异可能未被粗标签充分表达（DIFF-14/15/19）；③样本
   分组一致性（DIFF-20——已核验关闭，见 §3）。
5. **风险登记**（owner 原文）：若"抽取/标注差异"类在池内占比不低，SFT 可能把标注噪声
   当作真实任务—结构关系学习，增加生成不稳定性。占比判断依赖 P0 核验队列的原始程序
   对照结果，当前仅为样本级诊断，不代表全池同比例问题。
