  L119 可视化标签 `'Mean Biomass'`、L229 单位 `'AGBD (Mg/ha)'`、L385 导出名

## V3 汇总裁定

1. **4/4 对"结构相同"在源码级成立**：V3 范围内零结构标注错误，与 SAME 组 C 类=0 一致。
2. **1/4 描述保真度缺陷（SAME-15 指令 A）**：目标变量写错——这类缺陷在 RLE/canonical
   层完全不可见，只能源码核验发现。
3. **"标签表达力不足"的关注在本 4 对上转化为"字面量承载语义"**：时间范围（SAME-19）、
   指数命名（SAME-11）、循环参数（SAME-9）、目标变量（SAME-15）全部位于字面量层。
   → 直接支持双层表示设计（分析规划层 / 程序实现参数层）分工，不支持以扩词表解决。
4. **仪器教训（正反面）**：canonical 一致 ≠ 字面量一致（SAME-19/9 canonical 相同而源码
   不同）——核验包"caveat：canonical 不含字面量"的预警被证实必要；仅做 canonical 级
   对照会漏掉全部三个字面量差异。
