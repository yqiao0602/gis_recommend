# R20 草稿：聚合语义混淆（S021 温度极值 / S009 作物产量）

- **状态**：`draft_provisional`（agent 起草，待 owner 逐组复核）
- **候选类型**：聚合语义混淆（时间聚合 vs 分区统计 vs 面积求和）
- **素材**：`script_228758` vs `script_277196`（温度极值）；`script_74490` vs `script_74517`（作物产量，与 R18A 共享）
- **证据包**：`q2_stage2_evidence/R20.txt`

## 1. 原始任务与实现

- **温度极值**：TerraClimate 2018 年 `tmmx`/`tmmn` → 年均最大值/最小值 → 各国 `reduceRegion(mean)`
  → 直方图 + 2000-2020 月尺度时序图。
- **作物产量**：见 R18A（面积 `reduceRegion(sum)` 与时序 `sum` 两种聚合并存）。

## 2. L1 规划语义（聚合相关步骤单独建模）

### 温度极值（228758 / 277196）

| 步骤 | 意图 | 必要性 | 证据锚点 |
| --- | --- | --- | --- |
| P1 加载 TerraClimate | 数据源 | 必需 | `228758:L27` / `277196:L11` |
| P2 时间筛选（2018） | 时间窗 | 必需 | `228758:L29`（`filter(date, inicio, final)`）/ `277196:L13` |
| P3 缩放（×0.1） | 单位换算 | 必需 | `Bet` / `Tempescale` 函数（Q2 判读） |
| P4 **时间聚合**：年均 tmmx/tmmn | 由日/月到年 | 必需 | `228758:L33-35`（`mean()` over collection）/ `277196:L17-19` |
| P5 国家分区筛选 | 分区对象 | 必需 | `228758:L57-69` / `277196:L39-...` |
| P6 **分区统计**：各国均值 | 空间聚合 | 必需 | `228758:L71+` `reduceRegion({reducer: mean})` / `277196:L41+` |
| P7 直方图 | 分布输出 | 必需 | 直方图函数调用（二遍锚行） |
| P8 月尺度时序图（2000-2020） | 长时序输出 | 必需 | 时序图表块（二遍锚行） |

- **核心区分**：P4（时间维 reduce）与 P6（空间维 reduceRegion）是两种不同聚合语义，**RLE 的
  `AGGREGATION` 不区分**（Q1.5 抹平实证）。

## 3. 步骤依赖

- 温度：P1→P2→P3→P4→P5→P6→P7/P8；
- P4 与 P6 不可交换（先时间后空间 vs 先空间后时间为不同统计口径）；
- 作物：面积与 GPP 两条支路并行，在 P7 合并。
