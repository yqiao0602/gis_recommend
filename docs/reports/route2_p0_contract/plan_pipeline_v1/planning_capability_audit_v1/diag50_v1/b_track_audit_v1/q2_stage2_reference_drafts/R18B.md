  （`L49/L51`，`feat=tlist.get(i)`）——**输入坐标是外部数据（`tlist`/`a` 未在脚本内定义）**；

- “dams/reservoirs/point”措辞差异没有证据支持为几何差异（修正上一稿结论）。
