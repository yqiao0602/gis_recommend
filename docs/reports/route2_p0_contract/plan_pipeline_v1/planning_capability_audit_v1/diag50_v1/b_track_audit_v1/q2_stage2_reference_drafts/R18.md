## A. 作物产量家族（script_74490 棉花 vs script_74517 大豆）

### A1. 原始任务与实现

村级作物产量估算：MODIS/GCOM-C 的 GPP 与 LAI + 作物分类 + CCE 实测产量 → 村级产量分配与
CSV 输出。A=棉花（Aurangabad），B=大豆（Nanded）；两脚本同构，参数与作物字面量不同。

### A2. L1 规划语义

| 步骤 | 意图 | 必要性 | 证据锚点 |
| --- | --- | --- | --- |
| P1 选择行政区/村 | 空间单元 | 必需 | `74490:L37-39`（district filter）；`74517:L31-37` |
| P2 加载作物分类 | 掩膜作物范围 | 必需 | `74490:L47`（`MNCFC_Kharif2022/<district>_<crop>_LC10...`）；`74517:L43` |

| P4 累积 GPP（Terra/Aqua） | 生产力指标 | 必需 | `74490:L141-167`（MOD17A2H → sum）；`74517:L141-167` |
| P5 累积 LAI | 生长指标 | 必需 | `74490:L709` MCD15A3H；`L897` GCOM-C LAI；`74517` 同 |

- **依赖**：P1→P2→P3；P1→P4/P5；P3+P4+P5+P6→P7。
