## 6. 多参考关系（按 owner 第二轮规则重写）

**条件一致性是多参考的硬门槛**：

| 情形 | 判定 |
| --- | --- |
| 任务明确指定日期窗/水库集合，且两侧一致、差异仅为可接受实现变化 | 可作**同一任务多参考** |
| 任务明确指定条件，但一侧不满足 | **排除该侧**；不得因规划结构相同而视为正确参考 |
| 任务未指定条件 | 先明确数据集版本、默认配置来源与"是否允许不同配置"规则；**不得自动等价** |
| 日期窗/清单确实不同 | 作为**同构模板或条件化实例**保存；训练时显式提供条件 |

- 本组现状：A=2023-04-01/114 项；B=2023-06-01/93 项 → **条件不同**，当前只成立
  `isomorphic_template_of`；`multiref_of` 暂空。
- 命名修正：写作"**水库清单及其规模不同**"；仅凭 114 vs 93 计数不断言"同一清单的两个版本"
  （需逐项差异或数据源版本证据才能称版本关系）。
