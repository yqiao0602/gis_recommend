# R23 草稿：抽取缺口（S096 数组平滑 / S100 三分类器 / S110 福建六市）

- **状态**：`draft_provisional`（agent 起草，待 owner 逐组复核）
- **候选类型**：RLE 抽取覆盖缺口（**审计样本，不进入规划监督**）
- **素材**：`script_186175`/`187237`（S096）；`script_131053`/`131074`（S100）；`script_55526`/`55520`（S110）
- **证据包**：`q2_stage2_evidence/R23.txt`

## 1. 原始任务与实现

- **S096**：对硬编码 NDVI 数组做 Savitzky-Golay 类平滑（伪逆矩阵、11 点窗口、二阶多项式、
  两端扩展），输出原序列与平滑序列对比图。两侧 RLE 均为**空步**。
- **S100**：Madre de Dios 五类分类，同时训练 CART、RF、KMeans 三种方法。两侧 RLE 均压成
  **单 `CLASSIFICATION` 标签**（47KB 代码）。
- **S110**：福建六市 LULC 分类（RF + 指数 + 地形 + 面积统计），两侧 RLE 压成 **3 步**（32KB 代码）。
