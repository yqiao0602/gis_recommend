## 2. 仪器问题（必须先修正再继续）

1. **UI 旗标过宽**：正则把 `Map.addLayer/setCenter` 等展示调用全部计入，命中 90.6%；
   应改为 `ui.*` / `Map.onClick` / `Map.add`（交互控件）为主，展示调用单列。
2. **重复行旗标过宽**：91.5% 的短行（如 `});`）可能造成 71.5% 命中；应改为
   **≥3 个连续/重复的实质性行（≥15 字符）**，并区分声明重复与代码块重复。
3. **间接资产旗标过宽**：正则同时匹配了字符串拼接；应只匹配首参为裸标识符
   （`ee.ImageCollection(var)`），并记录变量名。
4. 旗标仅用于分层与提示，**不得直接作为准入或排除依据**（owner 原则）。

## 3. 关键发现：V2 划分存在同族跨 split 泄漏

| 家族 | 组件（split） | 说明 |
| --- | --- | --- |
| 油膜 manifest | `48801`(t) / `74228`(v) / `50842`(s) | 同一 "Identify oil surface manifestation" 任务族，指令 J 最高 0.660（<0.75），V2 未合并；三组件分属三个 split |
| 森林退化 | `45165`(s) / `103943`(v) | 同一森林退化/毁林任务族，指令 J 低于 0.75；跨 s/v |

- **根因**：V2 只用 J≥0.75 + 共享脚本 ID 合并；语义同族但措辞差异较大的任务未被合并。
- **影响**：若按 V2 直接训练/评估，训练与测试可能共享同一任务族 → 泄漏。
- **处置（未自动执行）**：新增**任务族合并 pass**（语义聚类 + 来源/目标/输出证据），
  生成 **split V3**；在 V3 冻结前，不得启动正式训练。不得为此拆散已冻结组件。
