## 1. 核心结论（一句话版）

**近重复指令对上的链条同/异，与任务逻辑的同/异几乎是两个正交的轴**：十对中
**0 对**的结构差异由任务分析逻辑驱动；全部真实语义差异（目标变量、阈值、时间范围、
数据资产版本、验证协议、指数命名、循环参数）都位于字面量/实现层，而链条上的
"结构差异"由 UI 挂件、重复块、重构、数据集版本、地图定位等非分析因素投影产生。

## 3. 五条可外推的审计发现

1. **链条相同 ≠ 任务等价**（V3 全体）：SAME 组四对全部"结构相同成立"，但其中三对
   存在真实字面量差异、一对指令失实——同码双描述下，哪侧描述忠实须源码裁定。
2. **链条不同 ≠ 任务不同**（V2 全体）：六对 DIFF 的结构差异全部无任务依据；分解为
   UI 挂件/实现多解/重复块/重构/数据集版本/阈值与修饰六种非分析驱动。
3. **抽取器无过、表示有责**：十对上链差异均忠实反映代码中的 API 调用差异（含 DIFF-6
   挂件、DIFF-5 重复块）——问题不在抽取噪声，而在 30 类 RLE 把分析步骤、UI 脚手架、
   重复块、重构、数据加载**等权投影**，同时对真正承载语义的字面量（阈值/版本/时间范围）
   **完全不可见**。
4. **机械层耦合的再解释**：Q2 机械审计的"结构差异率随相似度单调降（9.7%→5.8%→3.8%）"
   仍然成立，但十对证据表明该差异率的**内容构成**主要是非任务因素——"数据把任务变化与
   结构变化耦合起来"应精化为："数据把任务变化与**实现细节投影**耦合起来"。
5. **SFT 监督风险定性**：近重复对以当前链差异入训 = 向模型注入映射层不可约歧义
   （同/近指令 ↔ 多条仅差非分析因素的链），与 owner 批次三的风险登记吻合且已源码级坐实。

## 4. 对"如何构建可信规划训练集"的输入（选项清单，全部待 owner 裁定）

按十对证据的自然映射，四个候选方向（互不排斥；均未获执行授权）：

- **A. 规划监督链清洗**：链抽取排除/降权 UI 脚手架类调用（ui.*、Map.addLayer/
  centerObject、palette）与重复块归并——直接消除 DIFF-6/5 类伪结构差异。受控变更，
  须先冻结规则再重放（先 commit 后重跑的流程教训）。
- **B. 双层表示落地**：规划层=分析步骤；实现层=数据资产版本/阈值/时间范围/波段/验证
  协议。十对的全部真实语义差异都落在实现层——两层职责边界有源码级依据。
- **C. 指令保真度闸门**：对 SAME-15 A（失实）、DIFF-6 A（欠描述）类缺陷建立候选
  检测/抽检；描述与源码不符的行不得作为"模型应学不同结构"的证据（owner 纪律）。
- **D. 多参考机制**：DIFF-4（同指令两种合法实现）支持 Q3 结论的延伸——多解容忍的
  用武之地在近重复层与评估层，不在精确层。

**建议的下一步序**（若 owner 认可本结论）：①十对 → 扩样或全量机械复核（把四类
占比从 n=10 变成可外推的池级数字）→ ②A/B 方向设计冻结 → ③参考样本构建 →
④小规模对照训练（双层表示 vs 现有序列 SFT）。不改变"未对照前不算实证贡献"的裁定。
