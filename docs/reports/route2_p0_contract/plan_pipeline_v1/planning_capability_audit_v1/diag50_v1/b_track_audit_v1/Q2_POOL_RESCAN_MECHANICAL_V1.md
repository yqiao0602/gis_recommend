## 3. 校准（十对源码级已知样本的重分类）

SAME-15/11→same_code ✓、SAME-19/9→literal_diff ✓）；**3/10 分歧且机制已知**：

1. **DIFF-5 → small_literal（真值 duplicate_block）**：集合对称差对重复块**盲**——
   重复调用不改变调用**集合**，只增加重数；计数型信号（dup_lines/canonical 重数）
   才能区分。⇒ 167 个 small_literal 中应混有未知比例的重复块变体。
2. **DIFF-4 → duplicate_block（真值=实现级合理多解）**：真实实现差异可伴随顺带重复
   代码。⇒ 27 个 duplicate_block 中应混有实现多解。
3. **DIFF-12 → small_literal（真值 asset_version）**：级联顺序所致的小偏差。

DIFF-20（不在优先包内，单独核）：属 template_multiplicity——该类全池恰 4 对，量级
与"精确同指令异模板仅 18 组"的 Q3 结论相容。

**登记纪律**：以上三点为运行后发现的已知偏差，按预注册纪律**不做赛后调参重跑**；
类分布按"候选流行率"解读，真值由判读样本（§5）裁定。机械层职责边界（owner 原文）：
SHA-1/逐行 diff 能判代码同异与字面量位置，**不能单独判断分析意义**。
