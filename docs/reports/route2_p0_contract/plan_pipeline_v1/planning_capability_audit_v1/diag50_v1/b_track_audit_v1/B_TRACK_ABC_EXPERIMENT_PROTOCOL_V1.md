## 1. 三组定义与归因边界（已批准，冻结）

| 组 | 数据/监督 | 回答的问题 |
| --- | --- | --- |
| A 原始序列 | 现有原始工作流序列监督（未治理） | 现有数据与监督方式的基线 |
| B 审核后序列 | 经关系审查/准入治理的序列监督（A/C1/C2 修复/M 可用；Q1/Q2 排除） | 数据治理本身的效应 |
| C 双层表示 | 在 B 的治理基础上，改用 L1 规划语义 + L2 条件映射 + L4 监督 | 双层表示在治理收益之外的增量 |

- **主比较**：B − A（治理效应）、C − B（双层表示增量）。
- **C − A 只作总量参考**，不能单独归因于双层表示。
- 若 B 同时改变样本量/长度分布/标签质量/训练策略，B − A 只能称"治理方案综合效应"，
  不得归因于单条规则。
- **多参考纪律**：`multiref_of` 全空，不得为提高指标临时放宽准入；多参考可用性只报告资格。

## 2. 指标定义（可复算口径）

### 2.1 首要指标（primary）

**必要步骤召回率（NSR）**，任务级计算后按**任务组**汇总：

```
NSR_task = |pred_steps ∩ gold_necessary_steps| / |gold_necessary_steps|
NSR = mean over tasks (NSR_task)      # 任务级等权；同时报告任务组级均值
```

- 匹配口径：**语义步骤级**为主（L1 意图/算子族映射，映射表随评估集冻结）；
  **算子级严格匹配**为辅助报告，二者分别列示，不混算。
- 预测步骤与金标步骤的匹配由预注册映射表判定，不由模型自评。
- 报告：点估计、任务组 bootstrap 95% CI（重采样单位=任务组，**不以步骤为独立样本**）。

### 2.2 关键规划指标（必须同时报告，不得被首要指标掩盖）

1. **任务约束覆盖率（TCC）**：逐任务检查时间/区域/指标/数据/输出约束，正确表达的比例；
   任务级等权。
2. **依赖关系正确性（DRC）**：金标依赖图中被预测满足的边比例（成对 precedence/dataflow）；
   任务级等权；仅对标注了依赖的任务计分。

### 2.3 共同门（co-gates，任一触线则不得判定成功）

| 门 | 定义 | 触线规则（相对比较组） |
| --- | --- | --- |
| 有害/多余步骤率 | 预测中不在金标且会改变结果的步骤 / 预测步骤数 | 相对比较组上升 **>3.0pp** → FAIL（比较组：B−A 用 A，C−B 用 B） |
| 长链退化 | **长链子集**上的 NSR 与 DRC 相对比较组的下降 | NSR 下降 **>3.0pp** 或 DRC 下降 **>3.0pp** → FAIL |
| 解析健康 | parse / invalid / hit_cap / termination **分别**统计 | 任一项相对比较组恶化 **>5.0pp** → FAIL |
| 异常项 | 空工作流、相邻重复、未链接步骤的发生率 | 任一项上升 **>5.0pp** → FAIL，并附样例数 |

**长链子集预先定义**：评估集冻结时，按参考工作流步数取**上四分位且 ≥20 步**的任务；
任务清单随 split manifest 冻结，评估前不得更改。不得用总体均值替代长链子集。

### 2.4 辅助指标（只报告，不作为成功门槛）

- 精确序列匹配率（保留，但**不作唯一主指标**）；
- 多参考可用性（只报告 eligibility；当前无多参考准入）；
- 输出长度保持、终止行为分布。

## 3. 成功/失败判定规则（可复算）

对每个主比较（B−A、C−B）独立判定：

**成功（demonstrated）**当且仅当同时满足：
1. ΔNSR ≥ **+5.0pp**（点估计），且任务组 bootstrap 95% CI **不跨 0**；
2. TCC 与 DRC 相对比较组的下降均 **≤3.0pp**；
3. 四条共同门全部未触线（§2.3）。

**未证明（not demonstrated）**：任一条件不满足。此时报告实际值、CI 与触线项，
不得用"点估计达到 5pp"单独宣布有效。

**联合口径声明**：本协议采用"首要指标 + 关键指标护栏 + 共同门"的联合标准；
若 owner 希望三项规划指标均需 +5pp，须在启动前另立更严格口径并写入本协议，不得事后选择。

## 4. 划分与测试集证据边界

- A/B/C 共用 `B_TRACK_SPLIT_MANIFEST_V1`（组件/独立组原子；同侧约束）。
- **当前测试集仅 3 个独立单元**——这是本实验的主要证据限制：
  - 报告测试单元数、任务组数、具体任务分布；
  - 不把工作流步骤当作独立样本来夸大有效样本量；
  - 结果定位为**初步对照证据**，不得仅凭一次测试宣称双层表示具有普遍优势；
  - 训练前审查是否存在可合法纳入的独立任务组；**不得拆散已冻结的连通分量或近重复组**来扩大测试集。
- 测试集不参与训练、模型选择、阈值调整、治理规则迭代；预测哈希先于金标锁定。

## 5. 数据构成报告（强制）

每组报告：纳入任务组列表与计数、排除任务组与原因、表示改变项（序列→双层）、
样本长度分布、Q1/Q2 排除清单。只报性能不报构成 = 报告不完整。

## 6. 训练条件冻结

- 同一基座模型、同一训练预算、同一解码设置、同一评估程序；
- 若某项必须不同（如 C 组输入表示），提前登记并在结果中单列；
- 训练配置、数据版本、评估脚本在启动前冻结并记录哈希。

## 7. 停止条件

- 任一共同门触线；
- 解析健康任一项恶化 >5pp 或训练不稳定；
- 空工作流/相邻重复/未链接步骤异常上升；
- 触发后停止该组，不得调参后在同一测试集重报。
