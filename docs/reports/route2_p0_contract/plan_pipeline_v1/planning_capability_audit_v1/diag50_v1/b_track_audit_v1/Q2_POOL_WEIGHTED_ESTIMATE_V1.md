## 4. 仪器层发现（机械漏检审计的设计输入）

1. **RLE 退化/极限压缩**：S096（1 空步——纯数组运算无映射）、S100（47KB→1 标签）、
   S110（32KB→3 标签）——纯数学/多阶段代码的抽取覆盖缺口，池级规模待普查；
2. **间接资产引用**（`ee.ImageCollection(landsat5)` 型）使数据集主张静态不可核
   （S078/S106/S110 家族）；
3. **脚本内注释-代码矛盾**（S039 spliting=0.5 vs 注释'80%'；DIFF-19 同型）——
   保真度缺陷的另一来源是指令转写自注释；
4. **非互斥样本划分**（S007/S035：lt 0.75/gte 0.25 重叠）与**定义未使用**（S008）
   两种可机械检测的实现缺陷模式。
