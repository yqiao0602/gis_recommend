## Instruction A（全文）

Task: Identify burn severity using dNBR
the workflow assesses wildfire burn severity in the Karabaglar region using pre- and post-fire Sentinel-2 imagery. It computes the Normalized Burn Ratio (NBR) from pre-fire and post-fire images, calculates the difference (dNBR), classifies burn severity into eight classes (e.g., high, moderate, low, unburned), and generates a classified raster map. Outputs include visualizations of NBR, dNBR, and classified severity layers, a legend for interpretation, and an area summary table reporting pixel counts, hectares, and percentages per severity class. The final classified dNBR map is clipped to a sub-region (geometry2) and exported to Google Drive.

## Instruction B（全文）

Task: Identify burn severity using dNBR
the workflow assesses wildfire burn severity in the Karabaglar region using pre- and post-fire Sentinel-2 imagery from July and August 2021. It computes the Normalized Burn Ratio (NBR) for both periods, calculates the difference (dNBR), classifies burn severity into eight classes (e.g., high, moderate, low, unburned), and generates a classified raster map. Outputs include visualizations of true/false color composites, NBR layers, dNBR in greyscale and classified form, a legend for dNBR classes, and an area summary table reporting pixel counts, hectares, and percentages per severity class. The final classified dNBR map is clipped to a sub-region (geometry2) and exported to Google Drive.
