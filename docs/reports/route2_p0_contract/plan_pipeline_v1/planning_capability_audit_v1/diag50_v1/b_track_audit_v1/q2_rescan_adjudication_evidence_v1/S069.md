Task: Update land cover probabilities over time
the workflow implements a Bayesian Updating of Land Cover (BULC) model that iteratively updates land cover probabilities using sequential satellite-derived land cover maps. It starts with a base land cover image and processes a series of event images (classified land cover at different times), updating pixel-level class probabilities based on transition likelihoods derived from crosstabulation or pre-defined truth tables. Outputs include time-series probability layers, confidence scores, classified BULC layers, conditional transition tables, and optionally exported multi-band images of all intermediate results for each time step.
