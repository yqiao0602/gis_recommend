## Instruction A（全文）

Task: Model coral reef stress index
Compute the Coral Reef Stress Evaluation Index (CRSEI) by integrating multiple environmental stressors and reinforcers derived from satellite and model data. It calculates habitat suitability scores for coral reefs based on sea surface temperature (SST), salinity, depth, SST anomaly, Degree Heating Weeks (DHW), wind speed, current velocity, cloud fraction, and SST variability. Each parameter is transformed into a health stressor or modifier score using piecewise linear functions, then combined through weighted addition/subtraction to produce a final CRSEI score between 0 and 1. The output is a normalized raster map of CRSEI visualized with a six-color palette and exported to Google Drive at 2500m resolution.

## Instruction B（全文）

Task: Assess coral reef stress index
Compute the Coral Reef Stress Evaluation Index (CRSEI) by integrating multiple environmental stressors and reducers derived from satellite and model data. It calculates habitat suitability scores for coral reefs based on sea surface temperature (SST), salinity, depth, SST anomaly, Degree Heating Weeks (DHW), wind speed, current velocity, cloud fraction, and SST variability. Each parameter is transformed into a Habitat Suitability (HS) score using piecewise linear functions, then combined into a final CRSEI score through weighted addition and subtraction of stressors and reducers. The output is a normalized CRSEI raster map (0–1) clipped to the EEZ, visualized with a six-color palette and exported to Google Drive at 500m resolution.
