## 1. 样本选择（冻结）

- 总体：A1 的 158 个受影响步中，**实验臂（v0_5）原始提示 ≤ 1,241 token**（原 B1/B2 箱）的步；
- **n = 47 步，覆盖 26 个任务**（任务清单见 `d1_v1/D1_SAMPLE_V1.json`）；
- 原始提示长度 849–1,237 token（服务器 Qwen tokenizer 实测）；
- 原始输出状态：**46 条非空、1 条空**。

**样本条件化声明（必须随结果报告）**：该样本几乎全部是"历史上成功输出"的步
（46/47 非空），因此**结论只适用于这类步**，不能外推到全部 158 步或整体系统。
排除原因：提示 >1,241 token（不满足"短提示"入选条件）；无其它排除。

## 2. 中性填充文本（逐字冻结，不得在结果后更换）

填充语料为一段约 **858 token** 的英文中性文本，主题为纸张制作与书籍装订的工艺史；
**不含 GIS/算子/参数/数据/任务/输出/指令/示例/候选名/推理提示**，不含重复句式与特殊分隔符。
全文逐字见附件 `d1_v1/D1_PADDING_TEXT_V1.txt`（SHA 冻结于清单）。

**插入位置**：紧随最后一张候选卡之后、`[Instruction]` 之前（保持原有元素顺序；
指令仍为提示末尾）。以两个换行分隔，不添加任何标题或说明文字。

**防隐蔽混杂**：同一段语料用于全部填充样本，仅按 token 数截断；不针对任务改写；
不重复拼接（本语料 858 token ≥ 单样本最大需求 801 token）；截断在 token 边界，
并记录实际 token 数。

## 3. 目标长度（token 口径）

- 目标：**1,650 token**（落在原 B5 区间 >1,570），允许 ±10 token；
- 每样本填充量 = 1,650 − 原始提示 token（849–1,237 → 需 413–801）；
- 远低于 TRUNC 4096，**不改变生成预算（maxnew 2048）**、不改变解码；
- 服务器 tokenizer 逐条实测并冻结 `D1_PROMPTS_V1.json` 的实际长度。

## 5. 指标与预注册判读

| 指标 | 口径 |
|---|---|
| 主指标 | 配对空输出率差（B − A），任务级 cluster bootstrap（26 任务，10k 次）95% CI |
| 机制 | 逐样本终止分布：IMMEDIATE_EOS / EOS / CAP_TRUNC / END_MARK；配对转移四类 |
| 决策 | POS/OOC/ABST/NODEC 分布（正确性裁定不在本诊断内，另行升级） |
| 一致性 | 自相矛盾计数 |
| 操纵核验 | 实际输入 token：A 臂=原始（849–1,237），B 臂=1,650±10；不达标即判"操纵失败" |
| 稳定性 | 本轮 A 臂 vs A1 历史同臂：空输出与决策类别的一致率 |

**判读规则（预注册）**：

- **支持长度效应**：B 臂空输出率显著高于 A（CI 不含 0），且机制向 IMMEDIATE_EOS 移动，
  CAP_TRUNC 变化 ≤ +3pp；
- **不支持简单长度假设**：配对差接近 0（CI 含 0 且 |差| < 5pp）；
- **不确定**：空输出上升但截断/自相矛盾同步上升，或操纵核验失败——不得归因于一般长度效应。
- 样本小（47 步/26 任务），任何结果只作方向性证据，不作总体性能推断；不单凭一个百分比下结论。
