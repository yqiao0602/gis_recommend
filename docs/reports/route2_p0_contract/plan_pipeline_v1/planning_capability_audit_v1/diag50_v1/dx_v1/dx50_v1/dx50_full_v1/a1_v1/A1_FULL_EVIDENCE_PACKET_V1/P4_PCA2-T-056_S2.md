## 任务与步骤要求

**Task PCA2-T-056 全文**：

Task: Classify land cover types
Classify land cover in the Limboto Bone Bolango watershed using Landsat 8 surface reflectance imagery from May 2019 to October 2020. It applies cloud and shadow masking via pixel QA, computes a median composite, and trains a Random Forest classifier using training samples for Settlement, Rice Field, Vegetation, and Water classes. The output is a classified raster map with four land cover categories, accuracy assessment (training and test), and a legend displayed on the map, exported to Google Drive.

**Step 2**：Median Composite Generation ｜ purpose: Create a single representative image by taking the median value across time series for each pixel ｜ input: Cleaned imagery stack ｜ output: Single-band median composite raster per band
