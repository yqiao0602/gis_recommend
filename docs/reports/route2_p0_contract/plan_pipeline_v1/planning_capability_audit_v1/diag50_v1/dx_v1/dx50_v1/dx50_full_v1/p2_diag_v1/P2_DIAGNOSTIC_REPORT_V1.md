## 0. 事件定义（冻结）

| 状态 | 定义 |
|---|---|
| EMPTY | `raw.strip()==""`（无可见文本） |

## 2. 仪器级发现（先于任何归因）

**空输出的 `term` 标签不可信。** runner 用**批级** `n_new = generated.shape[1] - maxlen` 判定
`CAP_TRUNC`（`dx_run_stage_v1.py:95-99`）；同一批里只要有一个样本跑到 2048，同批中**立即 EOS**
的样本也会被标成 CAP_TRUNC。实测：空输出中对照 23/33、实验 23/38 被标 CAP_TRUNC。

→ **空输出 ≠ 截断**；其真实机制是"无可见文本（极可能是立即 EOS）"。在修复逐样本生成长度
记录之前，任何"空输出是截断"的解读都不成立。

## 4. 三种解释的判读（owner 假设 A/B/C）

| 假设 | 证据 | 判定 |
|---|---|---|
| A 提示过长导致截断 | 截断率随长度**下降**（30→13）；截断与 cap 相关但与长度无关 | **否证** |
| B 空输出与长度无关 | 空输出率随长度**单调上升**（0→61%）；仪器 term 标签为批级伪影 | **否证**；空输出与长度强相关，但机制不是截断而是**立即 EOS/无可见文本** |
| C 特定步骤/候选内容 | 任务集中度 27%；位置效应 ≤7pp；卡占比 +2pp | **弱支持**（次要因素），非主导 |

**结论：主导机制 = 长提示（>~1250-1400 token）触发"无可见输出"；截断是另一小类且随长度下降。**
这三种情况对应 owner 提出的三分：**"根本没有输出"是主问题（38/158），"长提示下无法完成"表现为无输出而非截断，"生成了内容但无法形成有效判定"仅 5 例（NO_TERMINAL 4+1）**。

## 6. 建议的下一项最小干预（单变量 + 可证伪预测）

**先修仪器，再改生成——两步分开：**

1. **仪器修复（不改生成）**：runner 记录**逐样本**生成的 token 数（当前 `n_new` 为批级），
   并把 term 判定改为逐样本。可证伪预测：修复后"空输出"不再被标 CAP_TRUNC，
   且空样本的逐样本生成长度应≈1（立即 EOS）。
2. **最小干预候选（二选一，待 owner 批准后单变量执行）**：
   - **I1 卡片压缩至固定 token 预算**（如每卡 ≤N token，保留必填参数/描述），
     预测：B4/B5 箱空输出率从 ~40-60% 降至 B1/B2 水平（<5%）；截断率不变；决策类别分布不劣化。
   - **I2 只对超长提示做候选卡截断（Top-10 保留前 K 卡）**——同一思路的更强版本，
     预测相同但需额外检验"候选删减"的混淆（候选集变化本身是第二变量）→ **不推荐**作为第一干预。
   - 解码/预算改动（提高 maxnew、改 rep-pen）在仪器修复与 I1 结果之前**不做**。

## 7. 边界

- 只读诊断；未改任何生成配置；不进入 A1 计数；A2 冻结。
- 相关性≠因果：长度梯度是强描述性证据，干预需单变量 A/B 验证。
