## 任务与步骤要求

**Task PCA2-T-009 全文**：

Task: Classify land cover types
Classify land cover types using Landsat 8 TOA reflectance data and supervised machine learning classifiers (Random Forest and CART). Training and testing samples are collected from user-defined regions for seven classes: bosque, agricultura, pastizal, humedal, plantacion, agua, and urbano. The output includes classified land cover maps, confusion matrices, overall accuracy, Kappa index, and user/producer accuracies for model evaluation.

**Step 6**：Alternative Classifier Application ｜ purpose: Apply the CART algorithm to the same training data for comparison ｜ input: Labeled training samples from Step 2 and engineered features from Step 3 ｜ output: A trained CART decision tree model file.
