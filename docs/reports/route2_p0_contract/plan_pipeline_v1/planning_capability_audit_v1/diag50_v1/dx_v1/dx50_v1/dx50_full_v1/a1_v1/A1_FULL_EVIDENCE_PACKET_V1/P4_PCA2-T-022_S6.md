## 任务与步骤要求

**Task PCA2-T-022 全文**：

Task: Generate cloud-free Sentinel-2 mosaic
Generate a median composite of cloud-free Sentinel-2 imagery over a specified region for summer 2022. It applies a cloud masking algorithm with a maximum cloud cover threshold of 60%, filters images between June and September 2022, computes the median pixel value across the time series, and masks the result using a longitudinal offset from 11.7°E. The output is a true-color (TCI_R, TCI_G, TCI_B) visual mosaic displayed on the map, masked to a specific longitudinal zone, intended for land surface visualization or agricultural monitoring.

**Step 6**：True Color Extraction ｜ purpose: Derive RGB bands from the median composite corresponding to Sentinel-2 true-color channels ｜ input: Clipped mosaic from Step 5 ｜ output: Final true-color mosaic ready for display
