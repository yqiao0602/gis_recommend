## 任务与步骤要求

**Task PCA2-T-098 全文**：

Task: Fuse Landsat and MODIS NDVI
the workflow fuses Landsat surface reflectance and MODIS BRDF-corrected data to generate a high-resolution, gap-free NDVI time series for 2015–2016. It first computes Landsat NDVI with cloud masking using pixel_qa, then processes MODIS MOD09A1 NDVI with quality masking and temporal interpolation via linear and Savitzky-Golay filtering. A spatial neighborhood-based regression model is built by correlating MODIS-pixel neighborhoods with Landsat observations, enabling spatially adaptive fusion. The final output is a synthetic Landsat-scale NDVI time series (30m) that preserves Landsat's spatial detail and MODIS's temporal continuity, smoothed with SG filtering and exported as a multi-band image collection.

**Step 1**：Data Preprocessing & Quality Masking ｜ purpose: Clean input data by removing low-quality pixels based on provided quality assurance information. ｜ input: Raw Landsat Surface Reflectance and MODIS MOD09A1 data ｜ output: Cleaned Landsat Surface Reflectance Raster, Cleaned MODIS NDVI Raster.
