## 任务与步骤要求

**Task PCA2-T-080 全文**：

Task: Identify burned areas using spectral indices
Identify burned areas in a specified region using Sentinel-2 surface reflectance imagery from March 2019. It applies cloud masking using the QA60 band, masks water using JAXA ALOS PALSAR forest/non-forest data and MNDWI, filters non-vegetated and urban areas using ESRI Land Use/Land Cover (LULC) data, and computes spectral indices (BAI, BAIS2, TBR) to detect burn signatures. Burned area masks are generated based on thresholding of these indices, followed by Random Forest classification trained on ground control points to produce final classified burned area maps for two time periods (March 15–21 and March 22–31, 2019). Outputs include classified raster layers, accuracy assessment via confusion matrices, and overall accuracy metrics.

**Step 4**：Spectral Index Computation ｜ purpose: Generate quantitative measures sensitive to post-fire spectral changes ｜ input: Vegetated pixel stack from Step 3 ｜ output: Three separate raster layers for BAI, BAIS2, and TBR indices.
