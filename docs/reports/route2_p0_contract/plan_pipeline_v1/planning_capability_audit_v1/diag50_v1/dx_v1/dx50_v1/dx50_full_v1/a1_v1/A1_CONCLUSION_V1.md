## 4. 对预注册解释表的判定

预注册三行：
1. 正确选择增加且错误选择不增加 → 支持"补卡有帮助"；
2. 弃权减少但错误选择增加 → 更愿意作答、质量未同步改善；
3. 四项基本不变 → 卡缺失未必主要瓶颈或信息未有效呈现。

**判定：不满足任何一行的完整条件，不得宣称第一行通过。**

- 正确选择率 20.0%→36.4%（+16.4pp）——第一行的前半成立；
- 错误选择 1→3、率 3.3%→13.6%——**第一行后半不成立**；
- 但也不能套用第二行（"质量没有同步改善"）：正确选择显著上升，且有 4 对可复核的
  卡面解锁证据；
- 第三行不成立（指标非基本不变）。

**唯一可支持的表述**：
> 在冻结检索与候选集的 158 个受影响步上，补全 OTB 卡片使模型更多形成正确选择
> （6→8，20.0%→36.4%），其中 4 对可归因于卡面新增的决定性证据；
> 但错误选择同时增加（1→3，3.3%→13.6%），包括 1 对原本正确的选择被破坏；
> 正确性亦被生成侧截断/自相矛盾吞掉（正确→不可判 5 对）。
> 因此 A1 支持"卡片补全能解锁正确选择"，但**不支持"补卡降低或至少不增加错误"**。

## 6. 边界与限制

1. **样本**：158/293 受影响步；n=49 任务中仅部分任务贡献多步；步骤不独立（任务级相关），
   本结论不做显著性推断（预注册的 cluster bootstrap 仅在机械层报过一次：+4.4pp CI 跨零，
   在 owner 裁决后已不再适用，不得引用）。
2. **判读来源**：27 对 owner 独立裁决；25 对 owner 批量确认（基于 agent 核对表）。
   批量确认不改变数值，但**不等于 owner 独立复核**；若后续发现卷宗与摘要不一致，
   走治理变更流程，不静默覆盖。
3. **唯一变量**：S1 检索与 Top-10 冻结；本结论不能外推到"A2 意图检索"或重跑 S1 的情形。
4. **卡片证据边界**：多处判"证据不足不可判"（枚举未展开、mime 语义未载），
   这些不是算子能力缺失的证据；P2 enum 展开是解除这些不确定性的直接手段。
5. **不构成训练授权**：A1 不改变 S2 专项训练是否值得做的判断；A2 未启动。
