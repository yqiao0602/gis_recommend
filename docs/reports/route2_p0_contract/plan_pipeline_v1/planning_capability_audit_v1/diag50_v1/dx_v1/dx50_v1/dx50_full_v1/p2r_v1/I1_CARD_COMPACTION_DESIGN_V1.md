## 1. 唯一干预变量

**OTB 卡片表示长度**：对 A1 的 158 个受影响步，卡面按**固定规则**压缩；其余一切不变。

固定压缩规则（冻结，非按结果调参）：

1. 每张卡保留：标题行、`accepts:`、`outputs:`、`description:`（layer_c_intent 文本）、
   required 参数（全部）；
2. optional 参数列表只保留**前 8 个**参数名（其余省略，以 `…(+N more)` 标注）；
3. 整卡字符上限 **1200**（现 full_card 上限 1800）；超出按上述顺序截断，不新增任何文字；
4. 不新增 choice 值（P1 已验证其单独效应，避免与 I1 混淆）。

不允许改变：候选集合与顺序（同一 retrieval.json Top-10）、任务文本、S2_PROMPT 模板、
模型、解码参数、maxnew、S1。

## 4. 预注册分析视角（owner 要求）

1. **总体配对比较（主分析）**：同 158 步上 I1 与对照的空输出率差（配对计数 + 率）。
2. **按压缩前长度分层（固定分箱）**：沿用 B1–B5（原始提示 token 五分位 1104/1241/1388/1570），
   观察原属 B4/B5 的步骤是否受益；同时报告压缩后的**实际**长度分布，避免"压缩后跨箱比较"。
3. 逐对列出空→非空、非空→空、空→空、非空→非空四类转移。

## 5. 预测与判定规则（待 owner 确认）

- 强预测（非唯一判据）：原 B4/B5 的空输出率从 ~40–60% 降至 **<10%**；
- 安全预测：CAP_TRUNC 率变化 ≤ ±3pp；自相矛盾不增加；
- 决策安全：**错误选择计数不增加**（对变化对裁定后），合理弃权不被系统性破坏；
- 判定：主指标改善且安全项全过 → "I1 有效（受控证据）"；主指标改善但安全项破线 →
  "改善伴随代价"；主指标无改善 → "长度不是充分机制"，转查其他因素（不叠加新变量）。

**若空输出率下降但错误选择增加**：不得表述为收益，按预注册解释为"更愿意作答但质量未同步"。
