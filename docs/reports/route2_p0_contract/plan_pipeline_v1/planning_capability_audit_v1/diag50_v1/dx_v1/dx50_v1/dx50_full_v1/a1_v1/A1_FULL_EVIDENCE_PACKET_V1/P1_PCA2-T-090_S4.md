## 任务与步骤要求

**Task PCA2-T-090 全文**：

Task: Classify land cover types
Classify land cover into seven classes (riparian, agriculture, other vegetation, water, active channel, roads, built-up areas) within a HUC-2 watershed (HUC 16) using a random forest classifier trained on NAIP and Sentinel-2 imagery, terrain data, and auxiliary datasets. The output is a classified land cover map and an exported feature collection of training points.

**Step 4**：Classification Prediction ｜ purpose: Apply the trained model to classify every cell/pixel in the processed raster stack over the entire watershed. Input: Unlabeled feature stack from Step 1 and the trained model from Step 3. Output: Classified raster map where each cell contains one of the seven integer class codes. ｜ input: - ｜ output: -
