## 任务与步骤要求

**Task PCA2-T-083 全文**：

Task: Classify vegetation PFT types
Classify plant functional types (PFTs) over a specified region using multi-temporal Landsat surface reflectance data from 2000 to 2020. It computes percentile and standard deviation statistics of spectral indices (EVI2, NDSI, NDWI, NDII1, NDII2) and bands (green, red, nir), combines them with ALOS AW3D30 DEM-derived elevation and slope, and snow cover frequency. A Random Forest classifier is trained on stratified samples from MCD12Q1-based PFT labels to generate a classified PFT map; if only one class exists in samples, it defaults to a constant image. The output is a byte-typed classified raster clipped to the ROI.

**Step 7**：Classification Prediction ｜ purpose: Apply the trained model to predict PFT classes for all pixels in the study area ｜ input: All prepared raster predictors (indices, band statistics, elevation, slope, snow cover) ｜ output: Classified raster with continuous probability scores or discrete class predictions
