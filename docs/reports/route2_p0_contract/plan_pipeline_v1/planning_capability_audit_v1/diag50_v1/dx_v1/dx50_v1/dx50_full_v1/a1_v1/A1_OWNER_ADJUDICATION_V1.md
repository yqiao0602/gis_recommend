## 判读规则（冻结）

**POS≠正确选择，ABST≠合理弃权；NODEC=未形成有效判定，不得当弃权；OOC=选了候选集外
算子，按错误选择处理。**

| 指标 | 判定标准 |
|---|---|
| 正确选择 | 所选算子与当前步骤的功能、输入输出及必要参数要求相符，且在候选集合内 |
| 错误选择 | 所选算子不满足任务要求、证据不足却作确定性断言，或选择候选集外算子 |
| 合理弃权 | 现有候选及卡面证据不足以支持可靠选择，弃权是恰当的 |
| 误弃权 | 已有候选能够完成任务，且卡面提供了足够证据，但模型仍弃权或未形成判定 |

细节：功能上可能可用但**卡面证据不足**→不能凭外部知识判误弃权；**卡面写得很详细≠功能
描述正确**。

## 账本口径（owner 指令固定）

`NODEC` 不自动映射到四指标。审计账本保留两个**正交字段**：
- `decision_quality`：正确选择 / 错误选择 / 合理弃权 / 误弃权
- `output_validity`：有效 / 无判定 / 格式错误 / 输出截断

（防：生成失败误算合理弃权；无答案样本误算知识退化。）

## 附加裁定（2026-10-18 抽检两批，6 样本）：五条横切规则

- **R1 复合步骤闭合**：复合步骤中部分能力命中不升级为整体正确（T-032#S2 定标+大气校正）。
- **R2 截断 ≠ 无判定**：截断但含推理的 think → output_validity=截断 + decision_quality=证据不足不可判；
  只有真正空输出才是无判定（不计入四指标）；不得把无判定追溯补写成弃权或选择。
- **R3 大小写笔误不改变算子身份**：`otb:ImageClassifier` 按 `otb:imageclassifier` 计（在候选内），
  文本异常单独记录（T-090#S4）。
- **R4 卡面字段完整度 ≠ 决策证据完整度**：参数名/类型/数量齐备不证明枚举选项、算法能力与
  输出语义已披露（T-009#S6）。
- **R5 因果归因保守**：实验臂结果更好 ≠ 补卡解锁；直接因果要求对照臂形成闭合决策且卡面为
  唯一变量。
