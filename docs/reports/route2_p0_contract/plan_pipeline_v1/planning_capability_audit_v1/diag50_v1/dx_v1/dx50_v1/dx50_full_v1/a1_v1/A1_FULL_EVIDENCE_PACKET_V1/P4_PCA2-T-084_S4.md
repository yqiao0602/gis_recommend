## 任务与步骤要求

**Task PCA2-T-084 全文**：

Task: Classify aridity and climate zones
Compute a high-resolution, rule-based climate classification map using CHELSA v2.1 (1981–2010) bioclimatic variables. It derives annual precipitation (P_ann), high-sun precipitation (P_hs, Apr–Sep), and potential evapotranspiration (PET_ann) to calculate the UNEP-style Aridity Index (AI = P_ann / PET_ann). It then applies a hierarchical decision tree: (1) assigns base aridity classes (Humid → Arid Desert) based on AI thresholds; (2) refines land classes using latitude zones (tropical, north/south temperate) and seasonal precipitation concentration (HS_ratio) to distinguish Monsoon (HS ≥ 0.8 or HS < 0.2 in tropics/south) and Mediterranean (HS < 0.4 in north, HS ≥ 0.6 in south); (3) handles cold climates separately using hottestC (<15°C) and coldestC (<−20°C) to assign Cold Ocean (7) and Cold Land (9); (4) overlays summer thermal severity (via hottestC) and winter thermal severity (via coldestC) to produce a three-digit combined code (cold*100 + climate*10 + summer). The final output is a discrete classified raster ('combined') clipped to a user-specified U.S. state (e.g., Rhode Island), visualized with a custom color palette.

**Step 4**：Identify Seasonal Precipitation Patterns ｜ purpose: Distinguish monsoonal and Mediterranean patterns within defined latitude zones ｜ input: hs_ratio.tif, latitude_zone_mask.tif ｜ output: monsoon_mask.tif, mediterranean_mask.tif
