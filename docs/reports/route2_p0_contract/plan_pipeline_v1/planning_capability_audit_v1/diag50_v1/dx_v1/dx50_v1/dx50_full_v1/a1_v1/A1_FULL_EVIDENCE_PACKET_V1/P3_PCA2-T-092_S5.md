## 任务与步骤要求

**Task PCA2-T-092 全文**：

Task: Classify land cover types
Classify land cover types over a specified region using Sentinel-2 and Sentinel-1 satellite imagery from April to October 2017. It computes multiple spectral indices (vegetation, water, bare soil, red-edge) and integrates terrain (elevation, slope, aspect) and SAR (VV, VH) features. A Random Forest classifier is trained on ESA WorldCover 2020 reference data sampled within the region, producing a classified land cover map based on multi-source Earth observation inputs.

**Step 5**：SAR Feature Processing ｜ purpose: Generate coherency and texture metrics from VV/VH backscatter ｜ input: Step 1 output (raw Sentinel-1) ｜ output: Derived SAR feature rasters (e.g., coherence, ratio, texture statistics)
