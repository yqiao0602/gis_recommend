Task: Extract soil point temperature minima
Extract daily minimum temperature values from the DAYMET V4 dataset for a set of soil points (soilpts) over the period 2000–2001. It maps over each soil point, retrieves the corresponding 'tmin' pixel values via reduceRegion at 1000 m scale, and constructs a new feature collection where each feature contains the geometry, pedon_key, and time-series tmin values (or 'No data' if missing). The output is a flattened FeatureCollection (newft) with one feature per image-date and point, enabling point-based climate analysis for soil monitoring.
