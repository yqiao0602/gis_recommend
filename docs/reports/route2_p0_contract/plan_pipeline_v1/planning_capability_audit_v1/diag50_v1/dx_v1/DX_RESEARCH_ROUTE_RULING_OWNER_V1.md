# DX 研究路线裁定（Owner，2026-10-17）V1 — 已冻结

> 来源：owner 会话裁定，归档为权威文件。全文以会话存档为准，此处登记冻结结论。

## 已获证据支持的结论 vs 待验证假设（严格区分）

已证实：6 个'明确过度拒绝'全部推翻；4 例卡不提供足够证据；5 截断步解析器误计属仪器问题。
待验证：知识底座是否为最大瓶颈；补卡后 S2 提升多少；S2 专项监督是否仍值得做；规划层影响是否更大。
**卡核实证明的是原案例不能作为过度拒绝证据，不证明 S2 本身没问题、也不证明补卡能解决大多数拒绝。**

## A 轨验收标准（四项可检查指标）

1 功能描述完整性 2 输入输出完整性 3 参数信息完整性 4 证据可追溯性（官方文档/算法帮助/人工推断；未知必须标'当前证据无法确认'，禁模型猜测补全）。
补卡后须检查是否真实改变模型决策，而非只增加文本长度。

## S2 能力诊断三组条件对照（冻结实验设计）

条件1 原始卡（能力基线）｜条件2 补全卡（只换卡，模型/提示/候选/解码不变）｜条件3 补全卡+S2 专项训练。
同一批人工审核步骤 + 固定 Top-K；无正确算子样本单独记检索问题不混入。
判读：C2>C1 → 卡质量限制成立；C3>C2 → 专项训练有独立价值；C3≈C2 → 不扩大 S2 微调投入。
指标四分：正确选择率/错误选取率/合理弃权率/错误弃权率（防'更积极但更不准'）。

## 解析器协议（冻结）

当前版冻结不再用于优劣判断；v2 只改标记识别范围+单元测试（think 内/外/截断/空）；
用 v2 重算历史并保存新旧差异；**解析器版本纳入每次实验记录**。

## 推进顺序（冻结）

①证据底座修复 → ②评测仪器修复 → ③重建 S2 诊断基线（区分检索缺失/卡片证据不足/合理弃权/真选择错误）→ ④再决定专项训练。
规划层作为独立诊断线保留，不与 S2 卡问题混在同一实验。
原则：每次只在证据充分、责任边界清晰的样本上判断模型能力。


## 附加裁定（同日）：A 轨 P0 正式放行

- **P0（OTB 115 卡）放行立项**；P1（177 全裸 / GRASS 输出 304）、P2（enum 展开）、S2 微调全部暂缓；规划层诊断独立推进不停止。
- 边界：这是有明确边界的知识补全实验，不是全面重建知识库，也不是认定知识卡是唯一瓶颈。
- 验收四项：功能准确性 / 输入输出完整性 / 参数完整性 / 来源可追溯（官方文档/算法帮助/实际运行接口）；未知标"当前证据无法确认"，禁猜测补全。
- 验收须抽查 full_card() 渲染文本，确认新增内容真实进入 S2 Prompt。
- 实验保护：补卡前冻结 profile/pack/prompt/模型/解码哈希；补卡后出新版本不覆盖原始文件。
- 实验仍保留三条件对照与四分指标；记录候选集是否包含经人工确认的可行算子。

## 附带仪器发现（同日核实）：S1 检索语料实为算子 ID 字符串

- 代码读 profile 顶层 description 键，实测存在数 **0/1291** → 全部回退为 "ID | ID去冒号"；
  功能意图字段 layer_c_intent（27% 覆盖）检索器未读取；index_meta 的语料描述与实际数据不符。
- S1 覆盖 100%（1,291 全在索引内），但相关性=步骤文本 vs ID 词元串的表面相似度——抽查表 19 个
  检索缺失的系统性解释。
- **交叉风险**：P0 补卡不得写入 description 键（否则 S1 索引静默变化，违反"补卡不改检索"边界）；
  描述写入 layer_c_intent 或专用键；S1 语料升级另立受控变更（索引版本化）。

## 附加裁定（同日）：实验设计细化——三条件表升格为 A1/A2/B 单变量分离

- 三问分离：S1 检索（layer_c_intent.text 能否改善 Top-10 覆盖）/ S2 知识（候选已在 Top-10 时
  补卡能否改善选择）/ 规划模型（正确候选+完整卡下是否仍漏步/错序/早停）。
- **A1 卡片补全**（冻结 S1 检索文本+Top-10+模型+提示词，唯一变量=S2 可见算子卡）｜
  **A2 检索语料升级**（冻结模型+提示词+卡片版本+Top-K，唯一变量=ID 文本 vs layer_c_intent.text）｜
  **B 规划能力对照**（冻结独立测试集+评价规则，变量=Base vs 训练版本）。
- A1、A2 先分别做再测组合；A2 须记录可行算子是否入 Top-10 及排名/分数、四分指标、
  按类别与复杂度分层；区分「在库中/被 Top-10 召回/卡片足以证明适用」三态，不合并。
- 执行序：保留冻结基线，先做已放行的 OTB 卡片补全（=A1 证据底座）；A2 另立受控变更
  不静默改检索；B 独立推进。全文归档：`dx_v1/DX_EXPERIMENT_DESIGN_RULING_OWNER_V1.md`。
