## Owner 裁定原文（逐字归档）

这次 Q1 的结果很有价值，而且它确实修正了我们之前对 GEE 数据的一个判断：问题不是大量
完整工作流被重复，而是工作流内部的局部转移模式高度集中，同时现有语义标签过于粗糙。

我赞同你目前的裁定：Q2–Q4 完成前，不调整损失函数、不做重采样，也不把诊断任务纳入
B 轨训练。现在应该继续查明数据到底能提供什么规划监督信号，而不是提前干预训练。

### 1. Q1 到底告诉了我们什么？

完整工作流层：44,721 个精确模板；Top-10 只覆盖 6.2%——说明不能简单地把问题概括为少数
完整链条重复。
局部转移层：90.3% Top-100 bigram 覆盖率——表明局部操作转移高度集中，但不直接证明这些
转移是错误的。
监督语义层：30 个粗粒度语义标签——不同的真实分析步骤可能被压缩成相同标签。
链长分布层：11% 落入 25 步截断桶——需要区分真实长链与截断造成的长度信息丢失。

最关键的不是 90.3% 这个数字本身，而是三个现象同时存在：
- 完整链条多样，但局部转移集中。
- 程序实现可能很复杂，但分析语义被压缩到 30 个标签。
- 短链占主体，而长链样本存在截断问题。

这意味着模型即使没有记住完整工作流，也可能通过高频转移、常见起点和长度先验生成看似
合理的流程，却在任务条件变化时遗漏必要步骤。

**不过，Q1 还不能证明模型已经发生了这种过拟合。它证明的是数据存在这种结构性倾向；模型
是否真的利用了这些偏置，以及偏置是否导致性能下降，还要结合 Q2–Q4 和基础模型对照来判断。**

### 2. Q2–Q4 的研究问题表

| 审计 | 核心问题 | 对后续训练决策的意义 |
| --- | --- | --- |
| Q2 | 相似指令中，任务描述变化时，工作流结构是否相应变化？ | 判断监督数据是否真正编码了任务条件与规划结构之间的联系 |
| Q3 | 近重复指令对应不同工作流的比例是多少？其中有多少是合理的多解？ | 判断单参考序列是否会错误惩罚其他有效规划 |
| Q4 | 规划错误与训练池分布的关系如何？哪些错误在原始数据中就存在，哪些可能由训练引入？ | 区分数据质量问题与模型问题 |

Q2 是最接近"模型有没有理解 GIS 任务语义"的审计，但需要注意：仅仅发现描述变化、结构
不变，并不能直接判定数据有问题。两个不同任务可能确实共享同一组必要步骤；相反，任务
描述只变化一个约束，也可能要求完全不同的规划。**因此，Q2 最终最好不只是计算结构差异率，
还要对抽样案例进行语义审查，判断结构变化是否符合任务变化所要求的分析逻辑。**

Q3 同样重要。如果同一个任务存在多条有效工作流，训练数据却只保留其中一条，那么普通序列
SFT 可能把合理的替代方案也当成偏差。此前关于多参考工作流的研究，正好可以与这项审计衔接。

Q4 则负责把数据问题与模型问题真正分开。没有这一层，我们很容易把所有错误都归结为
"训练数据不好"或"模型没学会"。

### 3. 双层表示的职责界定

- **上层（分析规划表示）**：任务目标 → 必要分析步骤 → 步骤依赖 → 条件约束 → 预期输出。
  回答：为什么需要这一步？它依赖什么？什么结果才算完成？语义映射与一致性约束。
- **下层（程序实现表示）**：GEE API → 函数调用 → map/iterate → 数据对象 → 参数与执行细节。
  回答：这些分析步骤在 GEE 中具体如何实现？

现有 30 个 semantic_chain 标签可继续作为粗粒度基线，但不应被视为最终的规划语义体系。
举例：AGGREGATION 可能对应时间合成、区域统计或其他聚合行为——粗标签层面相同，但所需
输入、分析目的和下游依赖可能完全不同。

**建议：先从真实数据中识别哪些语义差异被当前标签抹平，而不是立即设计一套更复杂的标签
体系。否则可能只是增加标签数量，却没有增加真正有效的监督信息。**

### 4. B 轨当前阶段最终判断

现在还不应该进入大规模训练改造阶段。顺序：
1. 完成 Q2–Q4，保留审计记录和抽样证据。
2. 根据审计结果，确定哪些数据能支持任务条件、必要步骤和依赖关系的监督。
3. 建立一小批经过审查的规划参考样本，包含必要步骤、依赖关系以及合理的替代方案。
4. 再进行小规模对照训练，验证双层表示或相应监督是否比现有序列训练更有效。

**尤其要防止一个误区：双层表示是一个有理论依据的研究方向，但不是已经被 Q1 证明有效的
解决方案。它需要通过后续实验与现有粗标签方案比较，才能成为论文中有实证支持的方法贡献。**

核心研究问题：**现有 GEE 程序语料究竟包含多少关于 GIS 分析决策的监督信息，又有多少只是
编程实现和局部操作共现的监督信息？Q2–Q4 就是在回答这个问题。**
