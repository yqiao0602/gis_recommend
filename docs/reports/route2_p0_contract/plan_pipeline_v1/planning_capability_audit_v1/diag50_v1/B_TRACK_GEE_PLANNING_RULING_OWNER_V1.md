## 训练目标转向（冻结方向）

从「复现工作流序列」→「学习任务条件下的工作流规划」（条件规划学习，非操作共现学习）。
四个改造方向：①从原始程序提取规划监督信号（目标/必要步骤/条件步骤/依赖/中间数据语义/终止条件；
不能把源码无法可靠确定的意图当事实标签）②循环/高频模式双层表示（程序实现层+分析规划层；同模板降权、
异语义保留）③构造任务对照样本（相似任务不同目标/同目标不同约束/形似依赖不同；允许多等价方案）
④训练目标分阶段（先可靠参考数据→模板分组重采样→辅助监督：约束覆盖/必要步骤召回/依赖正确→验证集确认）。
边界：高频算子不机械降权，只控重复模板与过度集中分布。

## 诊断矩阵（规划能力诊断，基线+对照；先 GEE 层独立计算再评 QGIS 迁移）

实验 A 常见模式复现 / B 约束变化 / C 组合泛化 / D 长链与依赖压力(8+步) / E 等价工作流。
指标：必要步骤召回率、任务约束覆盖率、依赖正确率、冗余与有害步骤率、长链退化率、多参考可用率。

## 双轨纪律（冻结）

A 轨（知识库补卡）与 B 轨（GEE 规划研究）并行但各自冻结基线，不混实验。
50 诊断任务可用于识别错误机制，**不可训练后用同批证明提升**；冻结独立测试集，按任务语义与
工作流模板划分防泄漏。

## 立即动作（本轮指令）

**GEE 工作流数据「任务语义—工作流结构—重复模式」联合审计**，回答四问：
1. 多少比例工作流只是少数模板的重复实例？
2. 任务描述变化时，必要步骤/依赖是否随之变化？
3. 同类任务是否存在多个语义正确但结构不同的工作流？
4. 哪些错误是训练后出现的，哪些是原始数据固有的？
审计完成前，不凭感觉追加损失函数。
