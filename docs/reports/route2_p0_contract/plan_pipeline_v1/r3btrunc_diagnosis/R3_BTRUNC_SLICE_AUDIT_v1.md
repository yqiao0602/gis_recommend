## 2. ⚠️ >21 slice 的结构性受限（预检发现的第二个问题）

>21 slice 的金标 Plan：**p50 = 1,160 词（≈1,700+ tokens），max 2,681 词**——
**远超冻结推理配置的 W3 生成上限（max_new_tokens=560）**。该 slice 的 F1 存在天花板：
即使规划完美，560 tokens 也只能覆盖金标的前 ~1/3。

实证（现有三臂 items 的事后代理分析，非正式指标）：

| 臂 | ≤21: parse / exact / 预测词数 p50 | >21: parse / exact / 预测词数 p50 |
|---|---|---|
| A+B ep1 | 194/223 / 0 / 140 | 13/15 / 0 / 140 |
| A+B ep2 | 199/223 / 2 / 140 | 13/15 / 0 / 143 |
| A-only | 190/223 / 0 / 140 | 13/15 / 0 / 139 |

**三臂在 >21 slice 的预测全部停在 ~140 词**（vs 金标 p50 1,160 词）——
该 slice 无法区分三臂，其读数由"提前停止"行为主导。

## 3. 顺带的行为学发现（支持 R3-C/D 方向）

**所有臂、所有 slice 的预测长度都恒定 ~140-160 词**，与金标长度（154 ↔ 1,160 词）完全无关，
而训练 Plan 的 p50 词数恰好是 148。即：**模型输出的是"典型训练长度"的 Plan，
而不是按任务复杂度调节的 Plan**——Task-conditioned planning 未形成的直接行为学证据。
这条与 R3-B-1 的 token-阈值假说互补：即使 Yes/No 判别随训练量涌现（W2），
输出长度/结构的条件化在两臂中均未出现。
