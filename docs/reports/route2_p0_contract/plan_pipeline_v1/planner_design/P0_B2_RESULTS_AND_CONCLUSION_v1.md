## 2. ⚠️ 进入 P1 前的强制前置：V2a 负结果判例

**P1"终止专项 SFT"在 V2a 线有过一次预注册失败**（`v2a_p1_eos_sft_negative_result`）：

- V2a-P1：EOS 加权 SFT（λ=20）→ 预注册判**失败，质量净负**——与 P0-B2 B 臂同一失败模式：**终止被强化，发射被压制**；
- V2a-P2：trie-EBNF 约束解码 → invalid→0、E2E +0.047/+0.026（唯一生成端正收益）——即 **"解码侧结构化干预 + 修复"路线有过正例**，与 P0-B2 C 臂（结构化停止 + 独立修复子实验）形态一致。

**P1 设计必须回答 V2a-P1 失败的因果**：为什么 SFT 侧强化终止会压发射？P0-B2 的 B 臂（解码侧 rep-pen）与 V2a-P1（SFT 侧 EOS 加权）出现同向危害，提示"终止与发射在模型内部是耦合的"——单纯加重终止信号（无论 SFT 还是解码）都会牺牲完整性。P1 若直接复制"终止专项 SFT"，先验预期应为**高风险**。
