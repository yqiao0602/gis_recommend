## 两项规范发现（提案，待 owner 确认后并入规范正文）

**F1（正则形式规则）**：同一 repeat 结构不得同时用 per-stage repeat 与 pattern 组
两种方式描述（一份数据一种解释）。每结构二选一：相邻同 family → stage.repeat；
有序多 stage 交错 → pattern 组（anchor_seq 定位）。

**F2（不等次数分解规则）**：交错且次数不等时，用"等计数 pattern 组覆盖交错前缀 +
尾余字面 stage"分解（T6 实证：[A,L]×12 + A×12 表达 [A,L]*12+[A]*12，往返精确）。
禁止用 per-stage repeat 表达交错模式（会产生顺序错乱的全前缀展开）。

**F3（三项附加检查确认）**：① repeat_count=总轮数无歧义（T3 实证）；② 折叠需证据
（T7 反折叠实证）；③ 重展开比较对象 = raw 全链（owner 警告的"数据规范清理 vs 真实
信息损失"边界：尾部同 family 不同对象不折叠，折叠后无法往返的差异必须标注原因）。
