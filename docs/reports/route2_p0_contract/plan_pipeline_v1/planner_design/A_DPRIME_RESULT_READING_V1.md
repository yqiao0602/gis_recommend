## 附：三问失败归因（owner 2026-10-12 指令；ADPRIME_FAILURE_ATTRIBUTION_V1.json）

**Q1 训练轨迹**：loss 1.28(step5)→0.33(final window)——收敛正常；**梯度范数未记录**
（trainer 无此日志，仪表缺口登记给未来所有训练）；LR cosine 确定性。基于现有产物
无法检出异常单步更新——诚实结论：不可判定，非"无异常"。

**Q2 回归集中位置**：45 失控新增行 ∩ 53 覆盖退化行 = **44 交（Jaccard 0.815）**
——同一批行，非两种现象。且**全层受击**：T2×10/T1×12/NT_long×8/BS×6/GT×6/
**对照短链×3(共15)**；gold 6-15 段最重（22），1-5 段也有 4 行。

**Q3 机制（决定性）**：45/45 = **C 类（无完整 JSON 对象的无界前缀）**，B 类
（JSON 完成后继续生成）**零例**；post 全部撞 768 帽；**45 行 pre 全部是 EOS 正常
终止**（如 idx 814：pre EOS@148 tokens/7 阶段 → post 768 撞帽从未闭合对象）。

**机制结论**：λ=2 终点 EOS 加权破坏的不是"EOS 位置"，而是**更上游的结构闭合
能力**（收尾括号序列不再发射）——EOS 因此永远到不了。三选一中既非纯 (a) EOS
不再输出、亦非 (b) EOS 后移，而是 (c) 的更早形态：**闭合结构本身损坏**。
覆盖崩塌（bag 0→）是同一故障的从属结果（不可解析=0 bag），非独立退化。
