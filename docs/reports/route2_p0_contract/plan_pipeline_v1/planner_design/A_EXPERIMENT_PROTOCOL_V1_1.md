## 修正 1：终止原因记录分类法（核验项 2）

每行输出必须记录运行时实际终止状态，至少四分：

| 终止码 | 含义 |
|---|---|
| `EOS` | 模型自然终止（生成完整 EOS） |
| `MAX_TOKENS` | 达到 max_new_tokens 上限截断 |
| `OTHER_STOP` | 其他停止条件（如运行时异常、上下文超限）——必须附带原始状态串 |
| `PARSE_FAIL` | 生成已终止但输出不可解析——**与截断分开记录**，不得把解析失败直接等同截断 |

判定以生成终止状态为准；`PARSE_FAIL` 行须另注其终止码（EOS/MAX_TOKENS/OTHER）。
不新增任何停止规则；本条只约束记录，不约束行为。

## 修正 2：统计口径预注册（核验项 3）

- **主呈现**：逐行配对变化（基线 vs 实验臂，同 idx）+ 各层分母（n）+ 比例变化的
  Wilson 95% 置信区间。
- **T2_truncated_long（36 行）为全取普查样本**：直接报告实际改善数与比例变化
  （如 36 行中 k 行由 MAX_TOKENS→EOS 且解析成功）；**不得**表述为随机样本的
  显著性推断。
- **NT_control_short（15 行）超发对照**：小样本，"不显著恶化"仅作方向性证据，
  措辞须带分母。
- 预算充分性核验：以**实际输出 token 分布**与终止码构成为准（MAX_TOKENS 残余率），
  不得由 gold_n_stages 推断所需 token 数（阶段数 ≠ token 数；样本中
  idx=1024 有 1,464 gold 阶段 / 71,030 字符，为登记的已知例外行）。
