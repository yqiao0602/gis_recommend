## 5. 失控率配对统计（v0.2 核实版）

**统计对象**：同一 131 行（A1_SAMPLE_131 唯一 idx）上逐行的二元失控标志
（termination == MAX_TOKENS）。pre = A1 768 臂重跑（同 host 同栈，52/131 失控，
已冻结）；post = A″ 臂（同预算同配置）。构造 2×2 配对表：

|  | post 失控 | post 未失控 |
|---|---|---|
| pre 失控 | a | **b（改善）** |
| pre 未失控 | **c（恶化）** | d |

**检验 = McNemar 精确检验（单侧）作用于不一致对 (b, c)**；
**效果阈值 = b − c ≥ 26**（= pre 注册基线 52 的 50%，即"失控减半"的预注册
最小效应）。
**通过 = 两条件同时成立**（b−c≥26 且 p<0.05）。
分层（T1/T2/NT/ctrl）计数仅描述性报告。禁止以两个独立比例的区间替代配对检验。

## 6. 误伤逐行判定规则（v0.3：短任务集合已冻结）

**两集合共用同一套规则**（early_stop / coverage_loss / false_stop 定义见下表）：

| 集合 | 定义（pre 臂口径，冻结） | n | 门禁阈值 |
|---|---|---|---|
| **C3-long** | 诊断 131 行中 pre 臂 EOS 且 gold>10 | **32** | 误伤 ≤2 |
| **C2-short** | 诊断 131 行中 pre 臂 EOS 且 gold≤10 | **47**（2026-10-12 实测冻结） | **误伤 =0** |

清单 SHA 与逐行 idx 冻结于四查证据 JSON；训练后不得改变样本范围。

逐行判定（确定性）：

| 判定 | 定义 |
|---|---|
| `early_stop` | post 臂以非 MAX_TOKENS 终止，且 pred_n_stages **<** pre 臂 pred_n_stages |
| `coverage_loss` | bag-excl(post) < bag-excl(pre) − 0.01，**或**"新家族遗漏"（f∈gold ∧ f∈pre 预测 ∧ f∉post 预测；类别级） |
| **`false_stop`** | **early_stop 且 coverage_loss（同时成立）** |

- 缺一不算误伤：仅提前结束但覆盖不减 ≠ 误伤；仅覆盖小降但未提前结束 →
  归入 §7-3 覆盖退化通道；
- **口径限定（owner 注记）**：本规则度量的是**相对 pre 臂**的提前终止+覆盖损失，
  不等价于人工确认的语义完整性——§7-3 的整体覆盖指标因此必须保留；
- NT_long（15）分层描述报告；全量评测集独立报告，禁止跨分母比较。
