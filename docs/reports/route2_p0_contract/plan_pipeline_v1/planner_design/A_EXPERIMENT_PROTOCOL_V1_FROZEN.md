# A 实验：解码预算与终止控制 — 协议 v1（FROZEN，owner 裁定 2026-10-12）

状态：**FROZEN**。批准范围 = 本协议 + A1 小规模解码对照。A2 仅在 A1 达标后解锁。
B 有条件设计准入（A 完成后）；C 暂停；不训练、不批量改 Gold、不 RL。

## 机制假设（可检验）

部分解析失败不是模型不会生成，而是**生成未完成**：
冻结预测（p0b_768，max_new_tokens=768，greedy）的可信子集中 241 行解析失败
**100%** 伴随 `hit_max_new_tokens`；长链（>25 阶段）截断率 52.9%。

## A1：小规模解码对照（131 行，`A1_SAMPLE_131.json`）

| 项 | 基线组 | 实验组 |
|---|---|---|
| max_new_tokens | 768 | **2048**（预注册：p99 目标 ≈1232 tokens，留余量；71k 字符巨型行=登记例外） |
| 其余全部 | 模型权重/提示词/输入顺序/greedy/解析器/Gold | **逐项相同** |

分层：T2 截断长链 36（全取）/ T1 截断短中 30 / NT 非截断长链 15 / NT BAND_SELECT 20 /
NT GEOMETRY-TERRAIN 15 / NT 对照短链 15。种子 20261012。

**固定项（不得引入）**：无新停止规则、无 repetition penalty、无其他解码改动——
单变量归因（owner 约束）。

**执行前置条件**：
1. 模型工件 = 与 p0b_768 预测同一 checkpoint/adapter，SHA 对账后才可执行；
2. 需要 GPU（推理约 131×~68s≈2.5h@768；2048 预算按比例增加）——服务器恢复后执行；
3. 原始预测与新预测**并存不覆盖**；输出行级：终止原因 / 生成 token 数 / 解析状态 /
   生成阶段数 / 超发情况 / 各项指标。

## A1 判定（进入 A2 的门）

提高预算**有效**须同时满足：
1. 截断实质下降（T1/T2 层完成率显著上升）；
2. 完整输出可解析（原失败行解析成功）；
3. 阶段覆盖改善**未被**超发上升或生成成本抵消（NT 对照层超发率不显著恶化）。

若预算增加后仍大量截断或转为超发 → A 判 FAIL，不得仅凭提高上限认定有效。

## B 准入条件（A 后，仅设计不训练）

- 若截断下降而阶段遗漏仍突出 → 进入 B 数据设计。
- 先把漏选拆两类：金标阶段合理/模型未生成 **vs** 金标重复或粒度定义不可靠
  （用已冻结审计类：audited_pending 等归第二类）。B 首轮只针对第一类。
- 最小对照：相同训练数据+预算，加 presence 辅助目标；报告 BAND_SELECT /
  ITERATIVE_APPLY / SPATIAL_FILTER 召回或 presence F1 + 其他家族回归。
- 数据约束：只用证据充分标签；未决 repeat 计数不得转成监督目标。
- 待明确（owner 指出）：presence 标签 = "某阶段应出现" 还是 "某语义类别应出现"——
  两种目标不同，不得混为一个辅助头。
