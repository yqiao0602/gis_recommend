# 多解判别诊断集设计 v0

状态：MULTISOLUTION_DIAGNOSTIC_SET_DESIGN_V0 / 设计草案，待 owner 审定抽样方案
日期：2026-10-11
目的：区分"模型真实失败"与"gold 方差/表示差异"——校准 X4/X5 错误解释（owner 裁定实验 C 优先）。

## 1. 诊断集必须覆盖的三个维度

| 维度 | 案例形态 | 判定问题 |
|---|---|---|
| **D1 算子链多解** | 同一任务的多条合法算子组合（不同指数/不同数据源/不同实现路径） | 模型输出替代链时是否判错 |
| **D2 表示粒度等价** | 同一操作语义的显式展开 vs 紧凑重复表达（如 20 年循环：100 阶段展开 vs repetition_group 紧凑） | 两种表示是否都被判为正确 |
| **D3 表示粒度不等价** | 粒度选择改变语义的案例（如丢失年度区分、把并列分支压成单链） | 模型输出与 gold 粒度不同但语义也不等价时的判定 |

种子案例：**k=956（显式展开）× k=958（紧凑）配对**——D2/D3 维度的现成材料。

## 2. 构建来源与规模

1. **D1**：从 X4/X5 行 gold 审计（WS2 复核产出）中筛选"gold 一致但存在明显替代方案"的任务，人工构造 1–2 条替代合法链；目标 ≥10 案例；
2. **D2/D3**：从语料中检索同构重复模式（同邻接 ×N）与 repetition_group 使用的**成对对照行**（同任务类型、两种表示）；目标 ≥5 对；
3. 每案例记录：任务文本、gold 蓝图、替代方案蓝图（D1）/对照表示（D2/D3）、语义等价性判定依据。

## 3. 使用方式

- 评测时：诊断集行**双标判定**（对 gold 与对替代方案分别打分），取语义等价集合内的最高分；
- 标注规范：等价性判定依据必须逐案记录（进入协议附录），避免判定者自由裁量；
- 隔离：诊断集不进入训练；仅用于评测口径校准。
