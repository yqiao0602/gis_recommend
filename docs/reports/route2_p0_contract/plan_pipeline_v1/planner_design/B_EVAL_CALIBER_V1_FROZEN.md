## 三评测视图（全部必报）

### 视图 1：原始生成（测模型自身能力）

| 指标 | 定义 |
|---|---|
| 解析率 | parse_ok / N（N=全体，无剔除） |
| 终止类型分布 | EOS / MAX_TOKENS / OTHER_STOP / PARSE_FAIL（v1.1 四分法） |
| 阶段覆盖 | bag-incl / bag-excl / 家族 presence P/R/F1（BAND_SELECT 为头条） |
| 过生成比 | pred_stage_count / gold_stage_count 分布（中位、p90、>3× 占比） |
| 失控率 | MAX_TOKENS 占比（同 host 同栈口径） |

### 视图 2：围堵后输出（测部署系统行为，仅当围堵启用时与视图 1 并报）

| 指标 | 定义 |
|---|---|
| 围堵后解析率 | 截断+closure 后 parse_ok / N |
| 保留阶段比 | kept/gold 分布 |
| 误截断率 | 正常行（原 EOS）被截比例——按短/长分层报告 |
| 触发率与未触发率 | 失控行触发数 / 未触发行数（4/52 类） |
| 成本 | 生成 token 数（截断前）与砍去量 |

### 视图 3：端到端主指标（防"只看成功样本"）

- **分母 = 全体样本**，不可解析样本计入分母，不得剔除
- 失败率分解：解析失败 / 失控截断 / 覆盖不足 / 过生成
- 家族 presence F1（BAND_SELECT 头条）+ bag-incl 主数
- **单独报告**："阶段指标不可计算"的行数（=不可解析行），不得从家族 F1 分母静默消失

## 语法有效 ≠ 语义完成（强制双标记）

每行输出两个独立标志：

| 标志 | 定义 |
|---|---|
| `syntax_valid` | 生成文本可解析为合法蓝图 JSON |
| `semantic_complete` | syntax_valid **且** 过生成比落在预注册带内（暂定 [0.5, 2.0]，标注 provisional 待 owner 终定）且无失控特征 |

**owner v1.1 限定**：长度比带仅为**必要的长度异常检查之一，不是完整的语义正确性
判定**——比值落带内仍可能漏阶段或顺序错误，不得把 `semantic_complete` 当作
最终语义质量指标。围堵后"过长但可解析"的输出**不得**与正确工作流等同；
parse-inclusive 指标上升不得解释为规划能力提高（owner 原文入册）。
视图 2 结果一律标注 **"offline simulation, not deployed behavior"**。

## 围堵器边界记录（随口径入册）

1. 4/52 失控行无可检循环——围堵不覆盖全部失控形式；
2. 2 例长工作流误伤（idx 1503/1181）= **真实小循环的合法输出**——围堵器若部署，
   此二例必须纳入回归测试；
3. R1 定位 = 推理层安全护栏候选，非模型能力方案；部署与否须权衡解析失败减少量、
   长任务误伤率与成本收益。

## B 设计的既定约束（重申并入册）

- 不可解析样本不消失：计入分母 + 单独计数；
- 辅助监督目标只用证据充分标签：`audited_pending`、粒度不确定、机械 RLE 可疑
  重复计数不得转为监督目标；
- presence 标签定义：**类别级（owner 终裁 2026-10-12）**——"某语义家族应出现"，
  与现行 E2 presence P/R/F1 一致；不新增阶段级辅助头、不引入新标签体系
  （避免监督与评测目标错位叠加新变量）。
