## F1. 训练构成（维度①，owner 问题一）

核心流 37,044 行中 **35,501（95.9%）成功回连 Tier 池：Tier A 20,901（62.2%）/ Tier B 12,600（37.5%）**（歧义 1，未匹配 3,542）。

**Tier B 是结构性更难/更脏的 3/8 训练量**：

| 指标 | Tier A（n=20,901） | Tier B（n=12,600） |
|---|---|---|
| Plan 步数 p50 / p90 / mean | 4 / 10 / 6.5 | 5 / 16 / 7.9 |
| Plan tokens p50 / p90 / mean | 140 / 351 / 229 | 185 / 511 / 275 |
| branch_ratio 均值 | 0.058 | **0.233（4 倍）** |
| flow_breaks 均值 | 0.0 | **0.11** |

即：B 层贡献了训练中**绝大部分分支结构与流断裂模式**，同时按分层定义它也是质量较低的一层。
若 B 层监督含系统性噪声，其影响面 = 37.5% 行、约 42% 核心 tokens。**Tier-A-only 消融直接检验这一点。**

## F2. Task↔Plan 对应关系（维度③，owner 问题三）——精确匹配层面干净，排除

- 36,898 唯一任务 / 37,044 行；**仅 1 个任务对应 2 个不同 Plan**；无"弱任务（≤12 词）+ 强 Plan（≥150 词）"行。
- "一任务多 Plan / 弱 Task 强 Plan"这类监督稀释**不存在于精确匹配层面**。
- 注意边界：这只排除**文本级**歧义；语义级多解（不同任务措辞指向同一Plan、或同一任务语义下多Plan均合理）需嵌入相似度分析，超出本轮 CPU 诊断范围。

## F3. 长 Plan 双重截断（维度②，owner 问题二）——实锤的监督缺口

- 训练 Plan 步数极端重尾：**p50=5，p90=14，p99=49，max=1,099**（tokens p99=1,555，max 35,523）。
- **构建期截断**：1,766/37,044 行（4.8%）的 core 目标被砍尾，共丢 2,515,645 tokens（单行最多 50,774）——被砍的全是最长 Plan 的尾部步骤。
- **运行期截断**：max_len=1024 下 ep2 训练 tgt_trunc 3,868 行；preflight 采样 tgt p99=966 tokens。
- **W3 探针偏长**：金标步数 mean 9.2 / p90 19（训练 mean 8.1 / p90 14）；70/474（14.8%）超出训练 p90，12/474 超 p99；W4 dev 同型（金标 p90 19 vs 训练 p90 13）。
- **结论**：模型需要条件化的恰是长/新组合 Plan，而长 Plan 的训练监督恰好被双重削弱。与"W3 两轮持平"一致。
