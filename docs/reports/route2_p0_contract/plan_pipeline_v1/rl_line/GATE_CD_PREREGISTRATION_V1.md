## Gate C：反事实候选排序测试

### 构造（每任务基于一个基础候选，全标 synthetic）

| 变体 | 构造 | 预期 r5 行为 | 计数指标 |
|---|---|---|---|
| CF1 删一必要步 | 移除一个 required 槽位的承载阶段 | 判 missing（检出） | 检出数/总数 |
| CF2 补回 | CF1 + 还原该阶段 | 恢复 covered（改善） | 改善数/总数 |
| CF3 加冗余步 | 基础 + 1-2 个任务无依据阶段 | **奖励/判定不得上升** | 非上升数/总数 |
| CF4 改顺序 | 置换阶段顺序 | 判定完全不变（集合语义） | 不变量/总数 |

基础候选来源：Gate B 盲评中被 owner 判 `covered` 较多的任务优先（需要"必要步骤"语义锚）。
**数量**：≥6 任务 × 4 变体 = ≥24 个反事实对；全标 `synthetic`。

### 通过标准（预注册）

- CF1 检出 ≥ 95%；CF2 改善 ≥ 95%；
- **CF3 非上升 ≥ 95%**（冗余堆叠不得抬分——反过度生成诱导的硬门槛）；
- CF4 不变性 = 100%。
- 任一不过 → 记录反例 → 修规则 → **重跑 Gate C 全部变体**（不允许只重跑失败项）。

## Gate D：离线奖励排序分析（先冻结指标，后看结果）

### 数据

- 人工裁定集（Gate B 的 80 候选 + 既有 32 条裁定包 + 合成包 9 项）；
- 三种评分：结构奖励（r1-r4 formal）、r5 覆盖判定、合成 R = λR_struct + (1-λ)R_cov
  （λ ∈ {0.3, 0.5, 0.7} 网格；R_cov = coverage_ratio 校准版，非原始 missing 计数）。

### 预注册指标（全部任务级为主、候选级为辅，分母显式）

| 指标 | 定义 | 门槛（建议） |
|---|---|---|
| 任务内区分率 | 组内 r5 判定 ≥2 个不同值**且与 owner 标签方向一致**的任务占比 | ≥70% |
| 排序一致性 | r5 覆盖序 vs owner 判定的 Kendall τ（限定 owner 给出全序的组） | τ ≥ 0.6 |
| 误奖率 | owner 判 `omission` 的候选得分 ≥ owner 判 `covered` 候选得分的组占比 | ≤10% |
| 饱和率 | 全组同分的任务占比（信息真空） | 如实报告（不作单独门槛，但 >50% 触发红灯讨论） |
| CF3 交叉核验 | Gate C 的非上升结果在 Gate D 合成分上复现 | 同 CF3 |

### 统计纪律

- 任务数 < 10 的子集 → 结论标 `uncertain`；
- 禁止用 39/317、74/80 折算准确率/遗漏率（owner 十二轮）；
- r5 自身输出不得作为 r5 有效的证据——排序分析必须锚定 owner 标签。
