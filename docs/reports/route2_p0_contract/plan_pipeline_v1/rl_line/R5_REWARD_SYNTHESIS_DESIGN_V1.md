## §2 校准与防投机规则（预注册草案）

1. **归一化与缺失分量**：R_struct = formal training_reward ∈ [0,1]（gateway 语义）；R_cov = coverage_ratio ∈ [0,1]（not_required/uncertain 槽位已在分母外）；任一分量不可用时仅用可用分量并打 `component_missing` 标志，不默认 0；
2. **重复阶段**：R_cov 集合语义天然免疫（CF4 已证）；R_struct 不因重复扣分——重复的处置 = 审计附录记录 + 训练期监控量，不加惩罚；
3. **无效阶段**（None/拼写）：由 formal 的 r1c/r2 通道惩罚（已实现）——R_cov 不重复惩罚（防双重计账）；
4. **过度生成**：CF3 已证 R_cov/R_struct 均不因堆叠抬分（结构上安全）；训练期预注册监控三项：阶段数分布漂移、harmful-extra 率、无效阶段率（进 GRPO 契约的投机检查节）；
5. **requirement_uncertain / wrapper 不透明**：不入任何分母，进审计附录；wrapper 归属待 v0.6（§5）；
6. **投机检测**：预注册三类检查——阶段数分布 KS 检验、required 槽位覆盖率的任务级方差、无效阶段率；任一在训练期超预注册界 → 触发回滚评审；
7. **负 τ（−0.737）调查**：作为独立分析项（结构分变体由 entry 缺陷 formal=0 驱动的假说验证），**不据此否定格式合法性约束的价值**——格式合法性与工作流语义正确性是两个目标（owner 十三轮）。

## §3 INDEX 公式级验证设计（L1/L2/L3 分层；离线设计，不改现有奖励）

| 层级 | 检查内容 | 当前可执行性 |
|---|---|---|
| **L1 槽位覆盖** | 是否存在指数计算阶段 | ✅ r5 v0.5.1 即此层 |
| **L2 公式正确性** | 运算符/波段/公式（NDVI=(NIR−Red)/(NIR+Red)） | **需任务级公式金标 + 候选携带公式字段**；当前 Blueprint 无内部字段——金标可先行构造，验证待表示层支持 |
| **L3 数据流正确性** | 公式输入波段接线、后续步骤消费正确输出 | 需 DAG/数据流字段——同上，依赖 Serializer/Grounding 层 |

**公式级金标对照集**（可先行构造的任务级金标）：正确公式 / 波段互换 ((Red−NIR)/(Red+NIR)) / 分母错误 / 仅有 INDEX 标签无可核验公式 / 非指数阶段承载指数语义（wrapper）/ 与任务命名指数不符（要求 NDWI 给出 NDVI）。
**边界**：L1 通过 ≠ L2/L3 正确；本设计不改覆盖奖励、不入训练奖励、不解冻 Phase 2/3。
