## 2. 判定与关键事实

1. **中间带成立**：38.03% 高于 FAIL 线 31.85%（+6.18pp），低于 PASS 线 44.69%（−6.66pp）。
2. **比"中间"更锐利的事实**：Δ vs B2 = −1.66pp，**三个种子的 bootstrap 95% CI 全部整体位于零以下**——这个 3.4M 全前缀探针在链不相交 held-out 上**显著低于** backoff trigram，不是"持平略差"。
3. **种子稳定性极好**：SD 0.22pp，三种子结论一致——不是随机性，是该配置下的系统性质。

## 4. 其他诊断（不承载判据）

- 贪心自由生成（500 行）：op-set F1 0.191、长度比 0.378——从零小探针无长度监督，生成塌缩为短输出，符合预期，不影响判据。
- 全量 test（含泄漏链，secondary）：39.24% vs 不相交 38.24%——泄漏通胀 ~1pp，与 Gate 0 污染分析一致，链不相交纪律再次被证明必要。

## 5. 诚实边界（解读时必须携带）

1. **本结果界定的是"该冻结探针配置"的提取上限，不是数据的理论上限**：best_epoch=8=上限，val 选点面（0.4339）在 epoch 8 仍创新高——探针未饱和。更大/更久的探针可能收窄 −1.7pp；但按冻结判据，判定属于本仪器。升级仪器=新的协议修订，须 owner 裁决。
2. **MIDDLE 对 Gate 2 的含义是"降低先验"，不是"否决"**：3.4M 探针与 Qwen 规模相差 4 个数量级；探针证明的是"超越局部的组合结构在 3.4M 参数 + 8 epoch 下不可提取"，Gate 1 对路线是必要非充分（spec §7），Qwen 能否提取更多是 Gate 2 的实证问题。
3. 优化器空间已锁死（spec §10）；本报告不附带任何进一步调参建议。

## 6. 交 owner 裁决的问题（按 spec §5 中间带条款）

组合信号以局部统计为主（n-gram 形态）在本仪器上成立。选项：

- **A. 直接进 Gate 2**（C0 vs C1）：探针只是数据侧信号探针；真正的迁移问题（Qwen + GEE 预训练能否提升 QGIS 工作流）未被本结果否决，且 Qwen 的容量/先验是完全不同的提取机制。成本：GPU 排卡（在 A1/B1 之后）。
- **B. 以 n-gram 统计特征注入替代预训练进 Gate 2**：若组合知识基本是 trigram 形态，把 GEE 转移统计作为特征/检索信号可能比预训练便宜且可控。
- **C. 一次仪器升级后重判**（如 12L/d384 或 16 epoch）：证据支持"还能涨一点"（未饱和+短链已反超），但即便收窄也很难跨越 +5pp PASS 线——边际信息量小。
- **D. 停止迁移路线**：按 roadmap，仅 FAIL 触发此项；MIDDLE 未触发。
