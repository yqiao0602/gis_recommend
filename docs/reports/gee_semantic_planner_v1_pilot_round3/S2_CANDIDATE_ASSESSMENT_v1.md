## 1. GeoAnalystBench（GeoDS/GeoAnalystBench，Apache-2.0）

| 审查项 | 核验结果 |
|---|---|
| 任务文本来源 | **无法确认为独立撰写**。50 任务基于 GIS 平台教程/学术论文改编 + 专家复核；仓库未说明任务措辞是否独立于参考工作流/代码生成。存在与 G0 相同的反写风险：任务描述与"人工编号工作流"共存于每条记录 |
| 输出形态 | 评 workflow validity + 与人工工作流的相似度 + Python 代码。**最接近 duty 序列评测的形态**（人工工作流可直接投影为 duty 对照） |
| 参考答案完备性 | **未声明允许多条正确路径**；按相似度评分类似于单一参考答案。作为 B1 金标准须先定义可接受变体规则 |
| G0 层污染 | 与本 GEE 语料无生成关系（ArcGIS/geopandas 生态，非 GEE 脚本）；与 6 条开发样本无重叠（内容可抽查确认） |
| 预训练层污染 | Apache-2.0 公开发布，**高概率已进入主流基座模型预训练/微调语料**——与 G0 层污染是不同层次，须单列。作为 held-out 评测时，模型可能"见过"任务与参考工作流 |
| 评分成本 | 低：已有人工工作流结构，转 duty 对照表约一次性工程（ArcPy→中性 duty 投影） |

**分级：有条件适用。**
理由：形态最匹配（人工工作流可直接投影）、license 干净、G0 层无污染；但任务独立性未声明（可能教程反写）、预训练污染高、单参考答案需变体规则。

用途限定建议：作为 **B1 的有条件候选**，但 T 条件读数必须同时报告预训练污染风险；更适合作为 B3 投影表开发素材（人工工作流 → duty 的映射演练）。

## 2. AutoGEEval-plus（szx-0633/AutoGEEval-plus，无 license）

| 审查项 | 核验结果 |
|---|---|
| 任务文本来源 | **未声明**。调研报告记录"LLM 生成 + 人工审校"——若属实，任务由 LLM 生成，独立性主张更弱（可能参考了 GEE 代码模式） |
| 输出形态 | 评 GEE Python 代码生成（原子/组合/场景三级），pass 指标 + 资源消耗。**代码执行/生成导向，非工作流规划**；转 duty 评测需从参考代码反推职责序列——这正是 G0 已暴露的反写循环路径 |
| 参考答案完备性 | 未声明多路径支持 |
| G0 层污染 | 与 G0 语料可能部分同源风险（同为 GEE 域）+ LLM 生成来源不明；需抽样比对 |
| 预训练层污染 | 公开发布（即使无 license），预训练暴露风险同上 |
| 评分成本 | 高：无 license（须联系作者）、原子级 1,325 条是单函数任务（duty 序列过短，无分解价值） |

**分级：不适用（作为 B1 独立意图来源）。**
理由：LLM 生成任务（独立性最弱）、代码生成导向与 duty 评测形态错位、原子级任务无分解结构、无 license。组合/场景级 1,287 条作为"意图重写格式参照"的旧用途保留，但那是训练格式参照，不是门槛 B 评价。

## 3. GISAgentBench（arXiv 2608.01645，仓库未公开）

| 审查项 | 核验结果 |
|---|---|
| 任务文本来源 | 349 任务**全部来自 GIS Stack Exchange 实践者真实提问**——这是三个候选中唯一有强独立性证据的：真实用户带着需求提问，先于任何参考实现存在 |
| 输出形态 | 执行级：可执行参考轨迹 + 精确输出文件容差匹配。轨迹非评分主对象（仅粗类别诊断）。**评测形态是任务完成，不是工作流规划**；轨迹→duty 的投影可行但参考轨迹只是"多种正确解法之一" |
| 参考答案完备性 | 执行级 ground truth 天然允许多条轨迹通向同一输出——**多路径性质上被支持**（只要输出匹配即成功），这是执行式评测的固有优势 |
| G0 层污染 | 与 G0 无生成关系（Stack Exchange 来源）；与 6 条开发样本重叠可抽查排除 |
| 预训练层污染 | 论文公开（Stack Exchange 内容本身大概率在基座预训练语料中）——任务文本可能被模型见过；但参考轨迹在仓库未公开的情况下暴露有限 |
| 评分成本 | **高且被阻塞**：仓库未公开，需联系作者；即使获得，duty 投影需要从轨迹/输出反推任务分解，且需人工核验任务目标一致性 |

**分级：有条件适用（最高潜力但被获取阻塞）。**
理由：任务独立性证据最强（实践者真实提问先于实现）、多路径性质上成立；但仓库未公开 + 执行级形态需转换为 duty 评测 + 预训练对 Stack Exchange 的暴露须声明。

用途限定建议：作为 **S4 人写任务就绪前的首选候选**——若能获取数据，它是 B1 独立性最强的来源；获取前不阻塞其他工作。

## 5. 对门槛 B 的直接影响

1. **没有一个候选可以未经转换直接充当 B1 金标准**——与 GATE_B 第 6 节预判一致；
2. **B1 的近期可行路径改为**：
   - 短期：GeoAnalystBench 人工工作流投影为 duty 对照（B3 投影表开发 + B1 有条件试点，同时声明预训练污染）；
   - 中期：联系 GISAgentBench 作者获取数据（独立性最强）；
   - 并行：S4 人写任务（唯一 `independent_verified` 层来源，按原计划暂缓至以上两项有结论）；
3. AutoGEEval-plus 移出 B 候选，旧用途（意图重写格式参照）不受影响；
4. **B4 复述检测不依赖外部数据集**——用现有 6 条开发样本 + 不同实现即可启动设计，不受 S2 结果阻塞。

## 6. 预训练污染的统一声明（所有候选适用）

三个候选均已公开发布。即使任务来源独立，**基座模型可能在预训练中见过任务文本甚至参考答案**。这不是否决理由，但 T 条件的任何读数都必须附此声明；若未来需要严格无污染评测，S4 人写任务是唯一完全可控的来源。
