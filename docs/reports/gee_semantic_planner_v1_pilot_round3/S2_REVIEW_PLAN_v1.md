## 2. 审查项（每个数据集一张表，逐项给证据）

按 GATE_B_DEFINITION_v1 第 6 节执行：

1. **任务文本来源**：独立提出 vs 从代码/参考答案反写；须给出论文/仓库证据；
2. **输出形态**：任务完成 / 代码生成 / 工具调用 / 工作流规划；能否转换为 duty 序列评测；
3. **参考答案完备性**：是否允许多条正确分析路径；
4. **G0 层污染风险**：与本 GEE 语料 / 6 条开发样本重叠检查；
5. **预训练层污染风险**：与基座模型预训练语料可能重叠（单独报告，不与第 4 项合并）；
6. **评分成本**：不补写大量主观标签能否建立可信判定。

## 3. 结论分级（不许降标准凑数）

- **适用**：有证据支持任务独立性，且能建立可信 duty 评价规程；
- **有条件适用**：来源可能独立，但需转换或补充核验；
- **不适用**：不能为门槛 B 提供独立任务分解证据。

## 4. 方法与边界

- 优先只读审查：论文/官方仓库/HF dataset card 等公开描述；
- 需要下载样本时：单独目录、仅小样本、记 hash，不进入训练管线；
- 不构建任何训练数据；不运行任何模型；
- 输出：`S2_CANDIDATE_ASSESSMENT_v1.md` + 各候选证据表。

## 5. 停止条件

S2 审查表 + S3 探针设计（另行批准的设计阶段）完成后停止；S4 与扩量仍暂缓。
