## 1. 判定单位与指标层级

| 层级 | 检测器 | 判定单位 | 一致率口径 | 人工裁定性质 |
|---|---|---|---|---|
| **候选级** | A1 | 单个未声明候选变量 | 候选**集合**一致（召回+无多余）；三分类为人工专属，不计自动化一致率 | 三分类 + 证据标准 |
| **变量级** | A2 | 单个已声明变量（文件级绑定，JS var 语义） | 状态三分一致 + 后继使用数精确一致，**分列报告** | 状态 + 计数 + 备注 |
| **调用级** | A3 | 单个调用节点（AST CallExpression） | 四角色一致；require 类单列（人工无对应类别） | 角色四分类 |
| **行级** | （人工标签格式） | 源码行 | **不作为检测器一致率口径**；行内嵌套调用与行角色的差异计入"粒度差异"单独报告 | 行角色（仅当行内所有调用同角色时与调用级等价） |

## 2. 固定规则（吸收本轮全部判例）

1. **文件级绑定**：重复 `var` 声明=同一绑定，计数合并（emptyImage/empty/chartPanel 判例）；
2. **形参作用域**：函数参数按所属函数作用域单独计数，同名不同函数不合并；函数体内引用即使函数未被调用也计数（引用计数与可达性分层）；
3. **定义表达式内引用不计后继**；`return` 计一次消费；同一调用表达式内的接收对象不重复计数；
4. **重复区块累计**：同一绑定在多个同构区块中赋值/使用，按文件级累计（collTOres_im 判例）；
5. **可达性两层报告**：状态按引用计数；`globally_reachable` 标志单独记录（nbr/illuminationCorrection/cloudScore 判例），不混入状态；
6. **图表参数族边界**（规范附则，解决 53 项漂移）：传入图表/图例/UI 构建函数的变量=参与计算→`analysis_chain`（100133 修订规则为 canonical）；仅被最终展示消费→`presentation_only`；此规则 backward 不适用——旧标签经裁定表逐项决定；
7. **A1 证据梯度**：裸标识符→indeterminable；命名空间/接口形态或多行使用佐证→可 external_prebinding；自引用≠外部证据；missing_definition 需正例验证后才能判定检测器能力；
8. **unknown 保留权**：不可识别的方法/命名空间保留 unknown，不为一致率强制分类。

## 3. 指标报告规范

- 主指标 = **严格一致率**（冻结原始口径，不剔除任何项）；
- 敏感性分析（归一化/分层剔除）必须单独报告并公开规则，不得取代主指标；
- 粒度差异（行级 vs 调用级）单列，不计入检测器错误；
- 全部结果标注标注者模式（单人探索性 / 双盲），禁止混用。
