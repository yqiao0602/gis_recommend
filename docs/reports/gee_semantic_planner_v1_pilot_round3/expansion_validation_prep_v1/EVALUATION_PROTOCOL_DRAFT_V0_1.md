## 0. 总原则（owner 新增）

**A2 的用途标签与引用计数分别裁定**：状态按变量的实际语义用途判断；计数按源码中的后继引用判断。人工标签是待裁定基准，不因自动化规则更易执行而默认自动化更正确。

## 1. 判定单位与指标层级（采纳）

| 层级 | 检测器 | 判定单位 | 一致率口径 | 人工裁定性质 |
|---|---|---|---|---|
| 候选级 | A1 | 单个未声明候选变量 | 候选集合一致；三分类为人工专属 | 三分类+证据标准 |
| 变量级 | A2 | 单个绑定（见 §2.2 作用域限定） | 状态三分 + 计数精确，分列报告 | 状态+计数+备注 |
| 调用级 | A3 | 单个调用节点 | 四角色一致；require 单列 | 角色四分类 |
| 行级 | （人工标签格式） | 源码行 | **不作为检测器一致率口径**；行内嵌套差异计入粒度差异单独报告 | 行角色 |

## 2. 固定规则（v0.1 修订）

1. **状态与计数分开裁定**；
2. **引用计数以绑定为单位 + 作用域限定（owner 修订）**：同一作用域内重复 `var` 合并为同一绑定、计数累计；**不同函数中的同名形参是不同绑定，不得跨函数合并**（`script_7900:image` 类）。文件级绑定是组织单位，不代表文件内所有同名标识符同属一个绑定；
3. **赋值左侧不计引用**（`score = score.min(...)` 右侧计、左侧不计）；
4. **函数体内引用照常计数**；函数未被调用不改变静态引用数，另记录可达性；
5. **§2.5 可达性两层报告（正式采纳）**：独立字段 `status`（源码有效后继引用）+ `globally_reachable`（静态近似：是否从全局执行路径可达；**不得包装为已证明的运行时可达性**）。两情形区分：有静态引用但函数未被调用 ≠ unconsumed；赋值后零后继引用 = unconsumed；
6. **§2.6 图表参数族规则（owner 修订版，收紧后采纳）**：**按变量在下游链路中的实际语义作用分类，不按其传入的函数名称分类**——
   - 参与数据筛选、统计、转换或结果构造 → `analysis_chain`（如 `data`、`xVals`、`Ppctfills`/`Afills`/`AOIimage` 等经 paint 构建的影像）；
   - 仅承担标题、标签、配色、底图、面板样式等界面配置 → `presentation_only`（如 `BACKGROUND`、`xLabel`/`yLabel`、`AQrange`、`getTheChart`/`chartPanel`/`legend`、图表参数对象与图表对象本身）;
   - `xField`/`yField` 等依实际用法裁定（用于筛选/统计字段提取→analysis；纯展示配置→presentation）;
   - 双重用途优先 `analysis_chain`；
   - **禁止**"被 UI 函数消费 ⇒ analysis_chain"的一刀切推断；
7. **数字冲突逐处核验**：人工备注所列引用数与 `human_uses` 冲突时，以逐处可核验的源码引用为准，不推测补齐（`score` 6→5 判例）;
8. **A1 证据梯度**（不变）：裸标识符→indeterminable；形态/多行使用佐证→可 external；自引用≠外部证据；missing_definition 无正例前不得宣称检测能力；
9. **unknown 保留权**（不变）。
