# A2 评价协议 v1.0（冻结）

状态：EVALUATION_PROTOCOL_V1_0 / FROZEN（2026-10-10 owner 批准）
适用：A2 变量使用状态与引用计数的检测器-人工对照；未来新增样本统一执行本版规则。
前版：v0.1 草案 → 本版按 owner 五项批复与全部判例定稿。

## 1. 判定单位与指标层级

| 层级 | 单位 | 一致率口径 |
|---|---|---|
| 候选级（A1） | 未声明候选变量 | 候选集合一致；三分类人工专属 |
| 变量级（A2） | 单个绑定 | 状态三分 + 计数精确，分列报告 |
| 调用级（A3） | 调用节点 | 四角色一致；require 单列 |
| 行级 | 源码行 | 不作检测器一致率口径；差异计入粒度差异单列 |

## 2. 状态定义（v1.0 定稿）

- `analysis_chain`：变量实际参与数据筛选、统计、转换或结果构造；
- `presentation_only`：变量仅承担标题、标签、配色、底图、面板、图表配置等界面用途；
- **双重用途优先 `analysis_chain`**；
- 分类依据**变量的实际下游用途**，非其来源（统计计算结果的唯一用途若是图表配置，则为 presentation_only——maxValue/maxMedian 判例）或其传入的函数名称（禁止"被 UI 函数消费⇒analysis"）；
- `unconsumed` := **零个有效后继标识符引用（纯静态判据）**。变量是否进入有效下游结果链**不属于**本状态——由 `globally_reachable`（静态可达近似）与 `downstream_effective`（下游链有效性）字段另行记录（landsatTOAcloudmask 判例：引用 1 → 非 unconsumed；下游断头 → downstream_effective=false）；
- `undeterminable`：按规则保留，不强行裁定。

## 3. 计数规则（绑定与作用域）

1. 计数以**绑定**为单位：同一作用域内重复 `var` 声明=同一绑定，计数累计；**不同函数中的同名形参是不同绑定，不得合并**；
2. 赋值左侧不计引用；`return` 中计一次；**同一调用表达式中的同一标识符只计一次**（101095:image 判例）；
3. 定义表达式内部引用不计后继使用；
4. 函数体内引用照常计数（未被调用不影响静态计数，仅影响可达性字段）；
5. 数字冲突以逐处源码引用为准（审计包模式），不推测补齐。

## 4. 可达性与下游有效性（两层字段）

- `globally_reachable`：绑定是否从全局执行路径静态可达；
- `downstream_effective`：引用链是否进入有效下游结果；
- 二者均为**静态近似**，不包装为运行时证明。

## 5. 指标报告规范

- 主指标=严格一致率（冻结原始口径）；敏感性分析单独报告并公开规则；
- 行级/调用级粒度差异单列，不计入检测器错误；
- 已知检测器局限（F2：文件级同名合并 vs 分绑定）作为错误类型单独归类，不计为人工错误；
- 标注者模式强制标注；协议冻结前不发布一致率。
