## 0. 三个层次（owner 裁定明确，全程区分）

1. **方法规则正确**：检测器是否遵守已冻结的重建方法；
2. **自动化可靠**：检测器与独立人工裁定是否一致、错误类型是什么；
3. **扩大应用是否值得**：重建收益、未决比例、人工成本是否支持下一阶段。

不得以第 3 层总体一致率认定整个方法有效；不得因语义恢复率非 100% 直接认定失败。

## 1. 工作包 A：自动化边界检测

### A1. 外部预绑定检测（有条件采纳，按裁定修订）

未声明变量只能先判为**待判定候选**，不得仅凭缺少定义认定来自外部环境（可能为漏提取、动态赋值、缺失代码或脚本自身错误）。三分类判定条件：

| 分类 | 判定条件 |
|---|---|
| `external_prebinding` | 有外部环境证据：`require(...)` 导入、代码注释/任务文本声明外部提供、或平台已知预绑定名 |
| `missing_definition` | 有足够证据表明应有的定义缺失，或源代码存在相应缺陷登记 |
| `indeterminable` | 现有证据不足以区分上述情况（含动态赋值迹象） |

"未声明但被使用"（use-without-declaration）仅产生候选记录 `{definition_location: unavailable_in_source, first_use_line, classification}`，**不计入 external_prebinding 检测正确率**，直到人工裁定给出三分类之一。

回测验收：AOI/geometry/ftTrain 等已知外部变量全部命中候选集合；in-source 变量零误报。

### A2. 死代码 / 后继使用检测（采纳）

- 规则不变：变量定义后，遍历 R1 数据流图的可追踪后继（直接引用 + 容器成员 + 函数参数传递）计数 `post_definition_uses`；**不用文本计数**；
- 三分类：`unconsumed`（0 uses）/ `presentation_only`（仅进入展示 API）/ `analysis_chain`（进入计算链），均保留证据；
- 回测验收：pi_all（0 uses）判 unconsumed；Fire_Sus（12 uses）判 analysis_chain。

### A3. 展示层与分析层分类（修改后采纳，按裁定修订）

- 预注册静态 API 分类表：`presentation`（Map.addLayer / ui.Chart / ui.Panel / print / Map.centerObject 等）/ `export`（Export.*.toDrive/toAsset/toCloudStorage）/ `analysis`（其余 core chain）；
- **未知 API 不得默认归入分析层** → 进入 `unknown` 人工复核队列；
- **展示、导出、分析角色允许共存**：同一变量/同一语句可同时携带多角色标签，分别登记，不互斥；
- 回测验收：C2 图表缺陷（xProperty 错位）归入 presentation 并进复核队列，不污染分析链。

### A4. 重复边去重（采纳；规则细化见回测报告 §2.3）

- 主键 `(from, to, use_line)`：同源变量、同目标、同操作位置 → 同一逻辑边，合并保留；
- 合并时 `via` 不一致记 `via_conflict: true`，**全部 via 值与原始记录指针保留在合并记录内**，不丢失原始证据与来源；同变量对不同操作/不同证据 → 分别保留；
- 报告双计：原始记录数 + 去重后逻辑边数（并附严格四元组含 via 的合并计数）；
- 回测结果：269131 的 40→38 正确执行（2 组 via 冲突双保留）；其余 5 脚本 0 合并。

## 2. 工作包 B：小规模验证样本设计（修改后采纳，按裁定修订）

### B1. 样本量

- "每困难层 ≥5"只是**探索性覆盖下限**，不声称足以支撑可靠的总体统计推断；
- 对照脚本 ≥10；预估 30–60；最终数字在抽样后由 owner 确认；
- 困难层之间允许重叠，**同时报告各层样本数与去重后的脚本总数**。

### B2. 抽样设计（分层 + 独立随机）

- 保留 L1–L5 分层抽样（L1 外部依赖 / L2 死代码 / L3 展示混淆 / L4 重复子流程 / L5 多公式多路径，检测来源为 A1–A4 与文本模式）；
- **新增独立随机组**：从 G0 train split 中独立随机抽取一组脚本，**不以 A1–A4 命中结果作为入选条件**——用于发现检测器漏检（检测器未识别困难特征而脚本实际存在问题的情况）。可与现有对照层合并安排，但必须记录其独立抽样身份（`sampling_group: stratified | random_independent | control`）；
- 对照层职责更新：验证误报（stratified control）+ 发现漏检（random_independent）；
- 抽样约束：全部来自 G0 train split；排除六试点；确定性 seed + 算法 R reservoir；每脚本 pin SHA + 生成脚本 + 产物 hash。

### B3. 人工复核协议（按裁定修订）

- **盲标独立子集**：预先从复核样本中指定一个子集，由两名标注者在**不知道自动化结论**的情况下独立标注，完成后才对照与裁定——只复核已出现分歧的案例无法测量独立标注一致性；
- 自动化-人工分歧案例逐条归因（检测器规则缺陷 / 人工口径差异 / 真实边界）;
- duty 粒度争用样本仍由两人独立标注（承接 Step 1 Q3 遗留）；
- 分歧不平均，记录后裁定。

## 3. 工作包 C：扩展验收指标（候选阈值，冻结口径）

### C1. 实现细节固化率（≤5%，暂定确认，口径修订）

分母不得含糊。四类计数**同时报告**：

- `checked_units`：检查的总单元数；
- `judged_implementation_detail_candidates`：已裁定为实现细节候选的数量；
- `misassigned_to_duty`：错误提升为任务职责的数量；
- `undeterminable`：无法裁定的数量。

固化率分母 = 已裁定单元（`judged_implementation_detail_candidates + misassigned_to_duty`），不得用未检查/未裁定单元稀释分母；原始计数并列报告。任何单一固化案例逐条解释并登记；无法归因、无法修正的超标触发停止。

### C2. 自动化-人工一致率（≥90%，暂定目标，口径修订）

- **A1、A2、A3、A4 分别报告**一致率与分歧案例，不使用单一汇总数字；
- ≥90%：达到目标；80–90%：未达标区间，需归因和复审，**不自动视为通过**；<80%：触发停止；
- 一致性测量基于 B3 盲标独立子集。

### C3. 其余指标

| 指标 | 判据 |
|---|---|
| 冲突静默调和 | **零容忍**；任意一次确认发生即 fail，不得被其他指标抵消 |
| 审计单元语义恢复率 | 报告分布（min/median/CI），不要求 100%，不作单一成败指标 |
| 证据支持率 | supported / supported_passing_only 分列，两态不合并 |
| 未决项比例 | 不设阈值；如实报告并分析主要原因 |
| 重复边比例 | 如实报告；去重规则执行后逻辑重复应为 0 |
| 人工复核成本 | 如实报告，用于评估全库可行性 |

### C4. 停止条件（满足任一即停止并回审）

1. 冲突静默调和 >0；
2. 固化率 >5% 且无法归因为可修规则缺陷；
3. 任一检测器一致率 <80%；
4. 出现六试点未见过的新型失效模式且现有规则无法分类。
