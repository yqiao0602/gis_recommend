## 1. 各检测器的判定单位、适用样本与计数规则

| 检测器 | 判定单位 | 适用样本（有效判定样本） | 自动化输出 | 人工裁定任务 |
|---|---|---|---|---|
| **A1** | **单个未声明候选变量**（非脚本） | 抽样全部脚本中 A1 输出的所有候选变量；目标 ≥10 个有效判定 | `candidate_pending_human` + 证据线索（comment 提及 / 自引用赋值） | 三分类裁定：`external_prebinding` / `missing_definition` / `indeterminable` |
| **A2** | **单个已声明变量的使用分类** | 盲标子集脚本中声明的数据变量（排除纯展示参数名后全部纳入）；每个变量一条判定 | 三分类：`unconsumed` / `presentation_only` / `analysis_chain` + `post_definition_uses` 计数 | 独立复核分类与计数是否正确 |
| **A3** | **单条调用语句的角色分类** | 盲标子集中预抽取的调用语句样本（含 presentation/export/analysis/**unknown** 四类，unknown 必须纳入）；每条调用一条判定 | 四分类 + unknown 复核队列 | 判定该调用角色归属；unknown 项裁定归入何层 |
| **A4** | **单条去重判定**（重复对是否同一逻辑边） | 盲标子集中被检测器标记合并的边对 + 等量未合并的相似边对（防止只考送易例）；每对一条判定 | 合并/保留 + `via_conflict` 标记 | 判定该对是否确为同一逻辑边、via 证据是否应保留 |

## 2. 有效样本数与不可判定处理

- **有效判定样本** = 自动化与人工**均可**给出判定的单位。以下三种情况计为 `not_judgeable`，**从该检测器一致率的分母中剔除并单独计数报告**（不得静默丢弃）：
  1. **类别不适用**：如某脚本无 A1 候选、无重复边对 → 该检测器在该脚本上无判定单位，不计入分母；
  2. **人工无法裁定**：标注者标记 `undeterminable`（如上下文不足以判断变量是否外部预绑定）→ 不计入分母，进入未决台账；
  3. **自动化无输出但人工有判定**（漏检）：计入分母且计为**分歧**（这正是 R 组/对照层的漏检发现职能）；
- 各检测器一致率 = 一致数 / 有效判定样本数，**逐检测器单独报告**；`not_judgeable` 比例并列报告；
- 每检测器有效判定样本 <10 时，该检测器本轮一致率标记 `insufficient_sample`（如实报告，不补抽——补样须 owner 批准）。
