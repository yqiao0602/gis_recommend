## 第 0 站：整体框架（2026-09-18）

### 学到的框架

所有训练 = 同一循环：**模型 θ → 输出 → 对照信号算损失 → 梯度下降更新 θ**。方法之间的区别只在"信号从哪来"：

| 家族 | 信号来源 | owner 项目锚点 |
|---|---|---|
| 监督学习 (SFT) | 人工 (输入, 答案) 对，逐位置对照 | M3-P1：8,817 行 (任务→gold L3 链) |
| 自监督 (预训练/DAPT) | 答案从数据自动抽取（预测下一 byte/被遮的词），**逐位置对照但标注零成本** | M1-R2 DAPT：174.7M 文本 CLM |
| 强化学习 (RL) | 无逐位置答案，只有**打分程序**对完整输出评分 | RLVR-P0：set_f1 + I/O 契约 |

**概念跳跃**：SFT/SSL 每个位置都知道正确答案；RL 只知道完整输出的最终得分——"位置 t 本该是什么"无人告知 → credit assignment 问题 → 整个 RL 算法族存在的原因。

### owner 的回答与讲评记录

- **Q1（DAPT 信号）**：核心答对（领域知识学习、无需人工标注）。精修点：不是"没有对错"——猜错下一个 byte 一样有 loss；是**答案免费自动**。SFT/SSL 损失结构完全相同，差别只在标注来源。
- **Q2（SFT vs RL）**：核心答对（SFT 有答案，RL 只有完整输出后的好坏判断）。卡点转移到"RL 的 loss 从哪来"→ 用类比解决：SFT 是"有标准点列，调 a,b 让曲线贴近点"；RL 是"没有标准线，模型自己画 N 条候选线，裁判（打分程序）给每条打分，学习=让高分画法出现概率变大、低分变小"。**RL 的信号叫 reward 不叫 loss——方向相反（loss 要小，reward 要大），但本质都是标量信号驱动参数更新；RL 的"损失"是从自己尝试的分数构造出来的，不依赖任何标准答案。**
- **Q3（加权 CE = 手工 credit assignment）**：用 M3-P1 实例讲解——42/49 预测以精确 gold 链开头但 0/49 exact（不会停，截断/重复）。CE 默认所有位置一视同仁，但 EOS 错一步毁掉整条链：位置重要性极不平等。λ=2 给 EOS = 人工指定"这个位置责任更大"。RL 中无需人工指定：不会停的链整体得分差 → 更新自动压制"不停"行为。**功劳分配从人工拍脑袋 → 从整体分数自动反推。**

## 第 1 站：梯度下降、loss 曲面、过拟合/泛化（2026-09-18）

### 学到的概念

- **梯度** = 数学上直接算出"往哪边调 loss 上升最陡"；梯度下降 = 朝反方向走一小步。90 亿参数的"地形图"= loss 曲面；a、b 版本只是它的两维特例。
- **学习率** = 每步步长。步子太大 → 跨过谷底落到对面更高处 → loss 震荡/发散。**信号越噪，lr 越小**：SFT 1e-5 vs RL 1e-6（ComfyUI-R1），因 RL 的奖励是抽样打分、比逐位置答案噪。
- **batch** = 每次用几个点估下坡方向（少=快但噪，多=准但慢）；**epoch** = 全部训练点过一遍。
- **过拟合** = 背诵能力 ↑ 做题能力停滞：训练 loss 与 val loss 的分岔点。**拿 checkpoint 取 val 最优 epoch，不是最后一个**（early stopping）。
- 过拟合可以是故意的：E4 冒烟把 100 条背到 loss=0 是**通过标准**（证明管线能学会任务格式），不是失败。

### owner 的回答与讲评记录

- **Q1（lr 太大）**：答对（"错过最佳下坡位置"）。精修出具体图像：跨过谷底、落到对面更高山坡，loss 震荡甚至发散。
- **Q2（train 降 val 先降后升）**：现象描述正确（"做新题开始挺好往后越做越差"），但未说出名称（过拟合拐点）与对策（取 val 最优 checkpoint = early stopping）。已用 M1-R2 SFT 日志的 `[EARLY STOP]`/`[BEST] composite=0.2802 at epoch 15` 实例讲透——owner 在服务器日志里亲眼见过这个机制在运行。

## 第 2 站：预训练范式——MLM vs CLM、DAPT/TAPT（2026-09-18）

### 学到的概念

- **为什么猜下一词能学出知识**：要猜准必须先懂；几亿句上的"什么接什么"统计规律逼出领域知识——**压缩即理解**。
- **MLM（BERT）vs CLM（GPT/Qwen）**：填空（双向视野、擅理解、不会生成）vs 接龙（单向、能生成）。M1 = BERT encoder（读懂题）+ decoder（写答案）各取所长；Qwen 一模型包办读+写——这就是 M1/M3 的架构本质差别。
- **DAPT vs TAPT**（*Don't Stop Pretraining*, 2020）：领域大语料继续预训练（174.7M 词）vs 任务数据集本身继续预训练（8,817 行文本）；互补不替代（R4 = TAPT 叠加在 DAPT 后）。
- **487.5M byte-tokens** = byte 词表下模型读了一遍 ~487.5MB 领域文本（coverage 100.18% ≈ 1 epoch）。对比 Qwen 原厂 ~10T token——DAPT 是大洋里加一杯水（精调先验非重造先验），这是 M2 DAPT 净效应为负的一种解释视角。

### owner 的回答与讲评记录

- **Q1**：答对（BERT 填空选手不能接龙生成；Qwen CLM 的任务本身就是逐词预测所以能生成）。
- **Q2**：owner 给出"**泛读 vs 精读**"类比（原话："我只有先了解了这个领域，我才知道这篇文献与我的任务的相关性，才知道值不值得精读"）——数据分布层面的正确理解，保留为个人锚点。补上机械层：损失形式相同，但 ① 预测对象不同（DAPT 预测领域文本的续写 vs SFT 在 prompt 条件下预测答案）② **loss masking**——标准 SFT 只对答案位置算 loss，prompt 位置被 mask 掉；DAPT 全文每个位置都算分。

## 第 3 站：SFT 的两个隐藏机关与根本局限（2026-09-18）

### 学到的概念

- **样本权重** = 每个样本的 loss 乘系数再平均 → 该样本的梯度贡献缩放。数据配比不只体现在条数，还体现在"每条喊多大声"（paper_v1: GEE 0.5×，QGIS ≥0.7×——在 8,283 vs 629 悬殊下调大 QGIS 相对音量）。
- **Teacher forcing**：训练时每步输入 = gold 真前缀（老师扶手）；推理时 = 模型自己的输出 → **exposure bias**。一步错 → 后续步步处于训练时从未见过的前缀分布 → **误差复合**。项目影子：M1-R1 塌缩、M3-P1 截断/重复、metric contract 的 "beam constraints not mirrored in ar_sampling"。
- **前缀来源谱系**（owner 关键提问引出）：① teacher forcing（gold）② free-running（自己写，早期学不动）③ scheduled sampling（混合渐变）④ **RL（永远自己写=on-policy，因此失去逐位置答案，只剩轨迹级总分）**——RL 存在的形式理由。车教练类比：扶方向盘练车 vs 只在终点打分的自己上路。
- **通向 RL 的桥**：SFT 在老师的答案分布上学；RL 在模型自己的输出分布上学 → RL 天然没有 exposure bias。

### owner 的回答与讲评记录

- **Q1（哪些 token 进 loss）**：答对（只有 gold 链 8 token 进 loss；"模型学的是怎么完成任务，不是预测用户会提什么任务"——原话保留，loss masking 理解到位）。
- **Q2（前缀谁写的）**：推理侧答对（自己写的、一步错步步错=误差复合）；训练侧提出关键问题："如果不是 teacher forcing，1-5 是谁写的？模型自己吗？"——**此问直接命中 RL 的动机**，用四档谱系回答。

## 第 4 站：RL 世界观——决策过程（MDP）（2026-09-18）

### 学到的概念（七成分对照表）

agent=被训练的模型；policy=模型本身（state→132 词表上的下一步概率分布）；state=任务文本+已生成前缀；action=第 t 步选的 token；episode=一条完整 L3 链（到 EOS）；environment=**几乎不存在**（确定性接龙规则）；reward=整条链完成后的打分（set_f1+契约，只在结尾给一次）。

- 生成一条链 = 8 次串联决策，前面的选择改变后面的处境（state 依赖全部历史 action）→ 功劳分配难的根源。
- **环境无存在感 = LLM-RL 的特征**；真正有环境的（工具调用、机器人）是 agentic RL——这就是路径一便宜的原因。
- policy 的本质是概率分布：RL 能做的一切 = 调整分布。SFT 也调分布，区别只在依据的信号（gold vs 自己轨迹的分数）。

### owner 的回答与讲评记录

- **概念辨析（owner 主动提问）**："RL 的 agent 和现在说的大模型 Agent 不是一个东西吧？"——答：两代同血脉。RL agent（1990s 术语）泛指决策学习主体；大模型 Agent（2023+ 产品语境）= LLM+工具+循环系统。连接点：agentic RL 里被训练的 RL agent 恰好就是大模型 Agent 系统；我们的链生成是最简单的退化 agent。
- **映射**：agent/state/episode 全对；reward 答成"给好的链更高分"——混入了更新行为。精修：**reward = 打分程序给出的数字本身（静态）；"给高分链更高概率"是参数更新干的事**。
- **environment**：答对（我们这没存在感；自动驾驶/机器人/工具环境才是主场）。

## 第 5 站：REINFORCE——策略梯度（2026-09-18）

### 学到的概念

- 三步推导：① 链概率 = 逐步条件概率连乘，模型只控制每步分布 ② 让高分链更可能出现 = 逐段抬高该轨迹每步选择 ③ 策略梯度定理：更新方向 ∝ **R × ∇log π(轨迹)**（R 大推狠、R 小推轻）。
- **loss = −R·log π(自己的轨迹)** → "REINFORCE = 模型自己给自己当老师，用分数当教案权重"——RL 训练框架长得像加权 SFT，只是教材来源（own rollout 替代 teacher forcing）和权重（分数替代 1）变了。
- **诚实细节**：奖励非负时（set_f1 ∈ [0,1] 恒如此），低分链也被抬升、只是抬得少——"惩罚"其实是"少奖励"。
- REINFORCE 对 credit assignment 的初版答案：不分配——整条轨迹的分数平均摊给每一步（每步权重同为 R）。

### owner 的回答与讲评记录

- **Q1（R=0 / R=−5）**：全对（零更新 / 方向反转为压低）。
- **Q2（全 0.4~0.5 平庸链直接当权重）**：答对本质（全被抬、幅度相近、区分信号弱）。

## 第 6 站：方差问题与基线——advantage 的由来（2026-09-18）

### 学到的概念

- 修法：权重 R → **R−b**（baseline）。定理：减任何与动作无关的常数**不改变更新的平均方向**（偏置项期望为零），但好基线大幅降方差——免费午餐。
- **advantage A = R − baseline**：>0 推上去、<0 压下来、"平均"即零信息。
- **GRPO 公式拆解**：A_i = (r_i − mean(组内))/std(组内) = 组内基线 + std 尺度归一（Dr.GRPO 指出 std 归一有 difficulty 偏置争议）。
- **零优势/零梯度问题**：组内全同分 → std=0 → 优势全 0 → 采样白烧。对我们要命：①多解 gold 易撞分 ②模型越确定同分越频繁（熵塌缩方向）→ 越训梯度越稀。解药：DAPO 动态采样（过滤同分组）、加大 G、**两级奖励再区分**（set_f1 同分用 I/O 契约分破局）。
- **基线取组内而非全局**：0.5 分的含义取决于任务难度；全局基线冤枉困难任务、放过简单任务；组内基线自动按任务难度归一。

### owner 的回答与讲评记录

- **Q1**：基线 0.5、三条低分被压——算对；"全 0.5 没区分度"直觉到位但不知道名字与后果 → 已补（零梯度/采样浪费/熵塌缩关联/DAPO 动态采样）。
- **Q2**：答对（组内更好）；理由"全局衡量模型能力、组内看具体任务"方向正确，栅格/矢量例子=任务间难度分布不同的正确直觉；已用"难度归一"框架重述。

## 第 7 站：PPO——clip 为什么能防崩（2026-09-18，重讲版）

### 讲法复盘（困惑 #5 的解法）

第一遍失败原因：一次引入 importance sampling + ratio + trust region 三概念。重讲成功路径：**只保留一个概念**——"推多狠？"→ 数字演示红线（0.5 → 上限 0.6=×1.2 / 下限 0.4=×0.8，越线梯度归零）→ 三句为什么（小步不崩/自动刹车/数据可多用几轮）。ratio=新旧概率之比、clip=设红线，仅此两词。

### 学到的概念

- **REINFORCE 的两笔债**：①数据一次性（更新一步数据即过期）②无刹车（一步推崩不可恢复）。
- **clip 红线**：ratio ∈ [1−ε, 1+ε]；advantage 估计只在旧策略附近有效——**留在数据有效的范围内做小幅更新**。
- **上限只对当批有效**：每批更新完重新采样，参考点刷新、上限重算——clip 限制每批步幅而非总涨幅（"小步、刷新参考点、再小步"）。
- ComfyUI-R1 ε=0.2 = 红线 ±20%；DAPO clip-higher = 单独放宽上界给探索留余地。

### owner 的回答与讲评记录

## 第 8 站：GRPO——总装（2026-09-18）

### 学到的概念

- 总装流程：数据采样（64 任务）→ rollout 采样（每任务 G=4 条，温度随机性保证互不相同）→ 打分（规则奖励）→ **组内**标准化（这 4 条互为基线）→ 加权更新（推压 + **红线** ±20%）→ **KL** 与推压混在同一次更新（β=0.001 松缰绳，不是单独的最后一步）。
- **两种采样**：数据采样（挑任务进 batch，同 SFT）vs rollout 采样（模型现场生成，RL 特有）——困惑 #6 根源。
- epoch 账：8,817÷64≈138 步=全池 1 遍；300 步≈2.2 遍。RL 报 step 不报 epoch。
- **重访即重采**：任务再次被抽中时现场生成新链，旧链随旧模型作废（第 7 站"参考点刷新"的落地）。
- β=缰绳松紧：总损失 = RL 目标 + β×KL(当前‖reference)。0.001=很松（信任奖励、防极端）；0.2=几乎不动；0=无缰绳危险。

## 第 9 站：DPO——偏好学习的另一条路（2026-09-18）

### 学到的概念

- 定位：GRPO=在线探索（现场采样打分更新）；DPO=离线重排（偏好固化成数据集，像 SFT 一样循环）。族谱上 DPO 源自 RL 目标的数学改写，训练形态属监督式；归"偏好对齐"家族。
- 输入=偏好对 (chosen, rejected)；我们的构对来源免费：beam top-k × composite 评分。
- 核心机制：拉开 π(chosen)/π(rejected) 相对 π_ref 同比值的差——冻结 SFT 模型当尺子。
- **关键精修：rejected ≠ 错误，是"更差"**。多解场景里 rejected 可能也是合理链；当"错误"学狠了会误伤合理非最优链、杀掉多样性。
- **天花板 = 候选池上限**：DPO 无探索，教不出 beam 搜不到的链——这是 M3 用 GRPO 的根本理由（随机采样可碰出全新有效链，打分程序验证即可入账）。
- 构对谱系：best-vs-worst（1 对）/ best-vs-rest（k−1 对）/ 全对（C(k,2)）——信息量与成本的折中。
- DPO 的 β ≠ GRPO 的 KL β：前者是拉开力度/偏离尺子容忍度，后者是防漂缰绳。
- M1-DPO = 最小改动：beam + composite + 自己的训练循环全现成，DPO 只是 loss 加一项。

## 后记（2026-09-21）：第 1 站深化重讲——从目标出发讲训练循环

**起因**：owner 主动要求不用"下山"比喻，从目标本身出发重讲"前向 → 损失 → 反向 → 更新"，指定例子 f(x1,x2)=g(w3·g(w1·x1+w2·x2+b1)+b2)。

**讲解要点**：① 前向要存中间量（反向要用）；② 梯度符号=损失上升方向，故更新取反方向；③ 反向传播=责任沿计算图倒着分摊，两条反复出现的规则：责任传递（乘局部倍数）与"权重梯度=责任×输入"；④ 数值实例：5 参数两层的玩具网，一步更新后 loss 0.41→~0，且 w2 的梯度是 w1 的两倍因为它输入 x2=2 更大。

**困惑清单追加（本轮暴露的两个卡点，已现场解决）**：
- #7 "前向传播是根据 x1,x2 去猜权重"——错在猜的动作只发生一次（随机初始化），前向是纯计算；之后是有方向的修正不是反复猜。
- #8 "x1,x2 与 f(x1,x2) 是确定的"——对单个样本对；但真实 f 从未已知，只有采样点。"拟合函数"=参数化函数在样本点上对得上+指望未见 x 上也对。

**owner 自述的循环理解（修正后确认到位）**：x,y 已知（样本层面）→ 权重初始为猜值 → 前向算输出 → L 量误差 → 反向定修正方向与幅度 → 千万次修正；目标=泛化而非背熟训练集。

### 追加（2026-09-21）：softmax

困惑 #9：softmax 是啥。已讲：logits 三不问题（可负/不归一/无对比）→ softmax 一石三鸟（e^z 保正保序放大差距，除和归一）；数字例 [2.0,1.0,0.1]→[0.66,0.24,0.10]，[5,1,0.1]→[0.975,0.018,0.007]（指数把分数差翻译成概率差）。三个出现位：decoder 每步 132 分数→策略 π；交叉熵=-log(正确项 softmax 概率)，锁配；温度 T 调平陡（GRPO rollout 多样性靠它）。argmax 不可导故不可训练，softmax=可导版 argmax——可反传是根本原因。
