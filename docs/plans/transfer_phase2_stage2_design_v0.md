## 0. 设计的实证地基（全部已冻结，设计不凭空）

1. FA 链：知识完好（teacher-forced acc = C0）；故障 = 自由生成控制（路径依赖，与 exposure bias 特征一致）。
2. DC 链：decode 期边际干预三连排除（mask / EOS bias / 状态条件 bias）——**训练期是唯一未试层**。
3. L-bench：**健康臂 C0 的 harmful_extra 也有 62.5%**——output-discipline 在健康臂上同样有可测量提升空间（Stage 2 不是只"防 A1 式退化"，是正向改进）。
4. 对齐文档 FROZEN：验收锚（C0 健康区/A1 失败区）、维度 A/B 判据、Stage-2 路由规则全部就绪——Stage 2 的验收可直接移植，零新指标发明。

## 1. 训练目标形式化（owner 五维 → 训练信号映射）

| 行为目标 | 训练信号来源 | 依赖 |
|---|---|---|
| 正确算子 + 正确顺序 | 标准 SFT 于完整 gold graph（C0 配方已证有效） | 无（v2a_A/B2 gold 即是） |
| 合法结构 | 同上（结构合法是 gold 图的固有属性） | 无 |
| **合理结束（EOS/终止）** | 待决 D2：样本构造保证终止可见性 / 终止位置温和加权（受 P1 教训约束）/ 结构化终止标记多任务 | 设计裁决 |
| **无无意义重复** | 待决 D2/D4：完整样本天然示范"不重复"；对比样本（膨胀 vs 干净）需构造 | 设计裁决 |

关键认识：**C0 的 SFT 已经学会了终止与基本纪律**（stopped 91.3%）——Stage 2 的纪律目标首先是"grounding 训练中不丢失"（防护性），其次是"把 harmful_extra 62.5% 往下打"（改进性）。

## 2. 数据构造（正负样本问题的选项空间）

- **主数据**：B2（Task+Plan 双条件 grounding，并行线 Step⑥ 设计已冻结；Teacher Plan 依赖 Frozen Stage-1 → **硬依赖 Stage 1 跑完**）。
- **纪律维度的样本选项**（D4 裁决）：
  - (a) 纯正样本：只用完整、干净、正确终止的 workflow（gold 天然满足；零新增成本）；
  - (b) 对比对：完整 vs 人工膨胀（插入冗余步骤）/截断（提前截止）的配对——供偏好类目标使用；
  - (c) 负样本显式惩罚：runaway 样本进 loss 做负向——最接近"训练版 repetition penalty"，P1 教训警示区。
- 无关数据禁入：A1 生成物不进任何训练集（封存纪律）；GEE 原始链不直接进 Stage 2（接口合同：API 不进 Stage 2）。

## 3. Loss / 目标形式选项（D1 裁决）

| 选项 | 内容 | 优点 | 风险/成本 |
|---|---|---|---|
| L1 | 纯 SFT 完整图（C0 配方 + B2 数据） | 最干净；直接可跑（B2 就绪后） | 纪律目标隐式，无显式保障 |
| L2 | SFT + 终止位置温和 EOS 加权（仅 gold 终止位，系数温和且冒烟门带 precision/recall 保护） | 直击 FA 定位的终止层 | P1 教训区（λ=20 失败）；须冒烟硬门 |
| L3 | SFT + 完成度多任务（辅助头：预测"workflow 是否已完整"/剩余步数） | 显式教"合理结束"，不碰主 loss | 新增头 = 架构改动，超"post-training 最小改动"范畴 |
| L4 | 偏好对目标（完整 vs 膨胀/截断） | 直接优化"不冗余、不早断" | DPO 族 = 训练路线扩张，需 owner 单独批准（RL 押后条款的精神延伸） |

**推荐**：主轨 L1（B2 就绪即跑），L2 作为可插拔对照（冒烟硬门保护），L3/L4 列为 L1/L2 结果后的升级选项——但此排序为提案，待 owner 裁决。
