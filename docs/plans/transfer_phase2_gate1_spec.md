# Gate 1 规格：GEE 组合可学性探针（预注册）

日期：2026-09-20 冻结（跑前成文；跑后判据不得回改，改判据=协议修订且 FAIL 原样保留）
性质：只读语料、无 QGIS 数据、无 Qwen、不占 route2 GPU 排卡（默认 CPU 训练）；不修改任何冻结数据。
前置：`transfer_phase2_roadmap.md`（owner 2026-09-20）、`docs/reports/transfer_phase2/gate0_v2_report.md`（PASS，勘误后数字）。

## 1. 要回答的问题（裁定逻辑）

路线级问题：**GEE 语料是否含有"可学习、且超越平凡频率统计"的工作流组合结构。**

Gate 0 已证结构存在性（条件熵 3.886 bit、结构保留率 87.1%），且 2026-09-20 实测频率基线证明**局部结构可泛化**：trigram 基线在链不相交 held-out 上已达 42.3%。因此本 Gate 的判别轴被基线本身抬高为：

> **模型（全前缀上下文）能否在未见链上显著超越 n-gram 局部统计？**

能 → 数据含可迁移的组合知识，进 Gate 2 设计；不能 → 按路线裁定**停止跨平台迁移路线**（roadmap §3 硬纪律）。

## 3. 探针模型（刻意小、刻意从零）

- **从零训练** decoder-only transformer：4 层、d_model=256、8 头、d_ff=1024、ctx=256、dropout 0.1、embedding 权重绑定，≈3.4M 参数。
- **为什么从零**：排除预训练先验混淆。Qwen 探针若"通过"，无法区分是 GEE 数据的信号还是先验，对 Gate 2 无预测力；从零小模型把问题隔离为"数据里有没有可学的、超越局部的结构"。
- 训练：AdamW lr 3e-4、wd 0.01、cosine→10%、warmup 500 步、batch ≈16k token、≤8 epoch、early-stop patience 2（val 链不相交 next-op top-1）；全位置 CE（BOS+ops+EOS，标准 LM next-token）。
- 种子 20260920/20260921/20260922 三次，**判据用三种子均值**。
- 设备：服务器 **CPU**（零 GPU 争用；估算 ≤2h/种子）。如迁移 GPU：须与 3f 会话对齐排卡，且三种子同设备类型并记录。

## 4. 基线锚点（2026-09-20 服务器实测，两段式判重，官方值运行时重算）

| 基线 | 链不相交 test | 长桶（≥12）链不相交 |
|---|---:|---:|
| B0 unigram | 5.79% | 5.75% |
| B1 bigram（backoff B0） | 29.84% | 30.10% |
| B2 trigram（backoff B1） | **42.34%** | **42.91%** |

**B2 已证明局部组合结构可泛化到未见链**——"可学性"问题因此不是"学不学得会"（已会），而是"超越局部性的部分存在且可学"。

## 5. 预注册判定（三种子均值，跑后不得回改）

- **PASS**：链不相交 test top-1 ≥ **B2+5pp（≥47.34%）** 且 长桶 ≥ **B2+5pp（≥47.91%）** → 超越局部性的组合结构存在且可学 → **进 Gate 2 设计**。
- **FAIL**：链不相交 test top-1 ≤ **B1+5pp（≤34.84%）** 或 长桶 ≤ B1+5pp → 数据无超越局部的可学组合结构（实现失效已由 §6 冒烟排除）→ **停止迁移路线**（roadmap 裁定）。
- **中间带**：介于两者之间 → 组合信号以局部统计为主，**交 owner 裁决**：附机制解读——若组合知识基本是 n-gram 形态，跨平台预训练的增量价值存疑，可考虑以 n-gram 统计特征注入替代预训练进入 Gate 2。
- 诊断性报告（不承载判据）：top-3 acc、分任务类型、分长度带、贪心全长生成的 op-set F1 与长度比。
- 统计注：位本 ~45 万，5pp 边际的 SE≈0.07pp；边际为实践显著性选择，跑前可调、跑后冻结。

## 6. 冒烟（正式跑前，判据预注册；冒烟后正式跑全冻结）

1. 2k 行子样本训练 2,000 步：loss < 4.0（unigram CE=ln(1003)≈6.91）；
2. 管线自检：探针内置基线模块在相同子样本复现 §4 锚点（±0.5pp）；
3. 容量自检：探针在 train 子样本上 next-op acc ≥ B2 同口径值（证明装得下局部结构）；不达标 → **仅冒烟阶段允许**修订容量/超参一次并记录。
4. 事故协议：正式跑因实现 bug 失效 → 修复重跑，**坏跑产物原样保留**（C-original 纪律）。

## 7. 与路线其余部分的关系

- Gate 1 是**必要非充分**：只证数据侧信号；迁移是否兑现由 Gate 2（C0 vs C1）回答。Gate 1 不训练 Qwen、不碰 QGIS 数据、不动 route2 排卡。
- 与 route2 四臂：B1 测的是"任务→语义工作流"的有监督迁移；Gate 1 测的是"组合结构本身的数据属性"——互不替代。Gate 2 C1 设计将引用 3f 的 C0/A1/B1 dev 曲线。
- 产物：`scripts/gate1_composition_probe.py`（训练+评测+基线一体，确定性种子）+ `docs/reports/transfer_phase2/gate1/`（`gate1_baselines.json`、每种子 `gate1_seed{S}_metrics.json`、`gate1_report.md`）。
