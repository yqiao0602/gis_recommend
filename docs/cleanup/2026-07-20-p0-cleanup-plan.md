# P0 工作区清理计划（2026-07-20）

## 目标

降低默认代码检索和上下文读取中的一次性实验噪声，同时不破坏当前 QGIS 数据漏斗、训练入口或回归测试。

## 本轮范围

- 归档未跟踪、无正式入口引用的 `scripts/_*` 一次性脚本；
- 归档根目录论文检索结果、文献下载器和文本抽取中间产物；
- 为上述本地归档和临时产物增加 `.gitignore` 规则；
- 在归档前记录原路径、SHA256、大小和归档时间。

## 明确排除

- 不修改或移动当前已修改文件；
- 不删除任何文件；
- 不移动正式脚本、当前 QGIS extractor、训练入口或回归测试；
- 不处理 `outputs/`、`outputs_v2/`、爬取语料、`.codegraph` 等大型数据根；
- 不压缩 `PROJECT_CONTEXT`、`progress`、`task_plan`，该工作列入下一阶段单独处理。

## 执行顺序

1. 枚举候选并生成 SHA256 清单；
2. 移动到已忽略的本地归档目录；
3. 校验源文件不再出现在工作区原位置、归档文件数量与哈希一致；
4. 运行只读 Git 状态和 Python 编译检查，不宣称模型或全量测试发生变化。

## 风险

- 未跟踪脚本可能仍被个人命令或外部服务器流程直接调用；因此只归档，不删除，并保留哈希清单。

## 执行结果

- 已归档 91 个未跟踪、无精确外部引用的下划线脚本；
- 已归档 11 个根目录文献/文本抽取产物；
- 已归档 2 个外部研究工具仓库；
- 102/102 个文件 SHA256 复核一致；
- 活跃 `scripts/` 保留 13 个已跟踪下划线脚本；
- `python -m compileall -q src scripts tests` 通过；
- 未运行全量 pytest：当前解释器缺少 torch，且仓库尚未配置稳定的 pytest testpaths。
